How to use these Cheat Sheets

This booklet is the night-before and last-week revision pack. Each topic is one A4 card: the definition you must write, the table or formula, a memory trick, the usual exam wording, and one Urdu line. Each chapter ends with a thorough 75-mark exam. It is not a textbook. Open the Student's Edition when you need a worked example.

How to revise with this booklet

  1. Two hours left. Read only the ★ Golden cards and the Golden index. Say each definition aloud.
  2. One day left. One chapter at a sitting. Cover the card, write the table from memory, then check.
  3. The night before. Read the night-before recaps. Do not start a new chapter.
  4. In the hall. Remember the recipe: Define. Explain. Example. Diagram. Working.

What each card holds

  • Definition — the 1-mark sentence. Write it exactly.
  • Points / table / snippet — the 3-mark and 5-mark body.
  • Remember — a mnemonic or trap to avoid.
  • Exam — how the board asks it.
  • اردو — the same idea in one spoken line.

★ Golden cards are high-yield. If time is short, skip non-Golden cards first, not these.
