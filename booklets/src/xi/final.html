Chapter 1 recap — Computer Systems

  • Discrete = counted (stairs). Continuous = measured (ramp). Digital systems use bits 0 and 1; they are reliable, accurate, easy to design and programmable.
  • Analog signal = smooth sine wave. Digital signal = square wave HIGH/LOW. Digital data resists noise.
  • AND · output 1 only if all inputs 1. OR + output 1 if any input 1. NOT ' inverts. NAND = NOT-AND, NOR = NOT-OR (universal). XOR 1 when inputs differ. XNOR 1 when inputs same.
  • Truth table rows = 2n. SOP = sum of minterms where output is 1. POS = product of maxterms where output is 0.
  • K-map: group 1, 2, 4, 8 adjacent 1s (power of 2, wrap-around allowed). Each group drops the variables that change.
  • SDLC: requirement → design → implementation → testing → deployment → maintenance. Waterfall = sequential; Agile = short sprints and feedback.
  • OSI 7: Physical, Data Link, Network, Transport, Session, Presentation, Application. Mnemonic: Please Do Not Throw Sausage Pizza Away. TCP/IP 4: Network Access, Internet, Transport, Application.

Chapter 2 recap — Computational Thinking & Algorithm

  • CT pillars: decomposition, pattern recognition, abstraction, algorithms.
  • Algorithm = finite, ordered, unambiguous steps. Pseudocode = structured English, not a programming language.
  • Bubble Sort: compare neighbours, swap if out of order; largest "bubbles" to the end each pass. O(n²).
  • Selection Sort: find the minimum in the unsorted part and swap it to the front. O(n²).
  • Linear Search: check one by one. Works on unsorted data. O(n).
  • Binary Search: list MUST be sorted. Repeatedly test the middle. O(log n). Trace with low / mid / high.
  • Judge an algorithm on correctness, efficiency (time and space) and clarity. Prefer binary search on large sorted lists; linear search on small or unsorted lists.

Chapter 3 recap — Programming Fundamentals

  • Python: high-level, interpreted. Variables are names; types int, float, str, bool, list, dict. input() returns str.
  • Arithmetic + - * / // % **. Relational. Logical and or not. Bitwise & | ^ ~ << >>.
  • Selection: if / if-else / if-elif-else / nested. Test from the top; first True wins.
  • for = known count + range. while = unknown count; always update the condition. break leaves; continue skips one.
  • Libraries: import math / random / datetime. Third-party via pip: NumPy, Pandas, Matplotlib.
  • Syntax = will not run. Runtime = crash + traceback. Logical = runs, wrong answer.

Chapter 4 recap — Data and Analysis

  • Data = raw facts. Information = processed data used for decisions. Database = organised related data. DBMS = software that manages it (reduces redundancy, improves security, sharing, integrity).
  • Table / relation; row / record / tuple; column / field / attribute. Primary key uniquely identifies a row. Foreign key refers to another table's primary key.
  • ER model: entity (rectangle), attribute (oval), relationship (diamond), cardinality 1:1, 1:M, M:N.
  • Referential integrity: you cannot orphan a child row. Cascade Update / Cascade Delete copy or remove matching child rows.
  • Access objects: tables, forms, queries, reports. Queries filter with criteria, wildcards (*, ?), AND/OR. Totals: Count, Sum, Avg, Group By. Charts visualise the result.

Chapter 5 recap — Application and Impacts of Computing

  • IoT = connected devices. Six parts: sensor, actuator, connectivity, processing, cloud, UI. AI = machines that learn and decide. Analytics = collect → store → clean → analyse → visualise.
  • Together: IoT (eyes) → Analytics (sort) → AI (brain) → actuator (action).
  • Sources: primary (firsthand), secondary (explained by others), tertiary (summaries). No author / date / references → do not trust.
  • Assistive tech: mobility, sensory, communication, cognitive. Goal: equal access, independence, inclusion.

Chapter 6 recap — Digital Literacy

  • Digital literacy = find, evaluate, create and share information with digital tools, safely.
  • Qualitative = words/descriptions. Quantitative = numbers. Strategies: interview, survey, prototype, observation, simulation.
  • Primary data you collect; secondary data already exists. Good survey questions are clear, single-idea, unbiased.
  • Present with spreadsheets (formulas such as =AVERAGE()), slides, infographics and reports. Cite sources. Follow the 12-step inquiry project from question to artefact.

Section B

  1. Analog: continuous, sine wave, e.g. human voice. Digital: two levels 0/1, square wave, e.g. computer data. Digital resists noise.
  2. NOR symbol: OR-gate shape with a bubble on the output. Y = (A+B)'. Truth: 00→1, 01→0, 10→0, 11→0.
  3. Decomposition = split a problem. Pattern recognition = reuse similarities. Abstraction = ignore extra detail. Algorithms = write ordered steps.
  4. Binary Search repeatedly halves a sorted range. If the list is unsorted, the middle value does not tell you which half to keep, so the method is invalid.
  5. m = int(input("Marks: ")) then if m >= 40: print("Pass") else print("Fail").
  6. Primary key: unique identifier of a row (e.g. StudentID). Foreign key: a field that refers to the primary key of another table (e.g. StudentID in Issuance).
  7. Sensors, actuators, connectivity, data processing, cloud computing, user interface.
  8. (a) primary (b) secondary (c) tertiary.
  9. Good: "How many hours per day do you use a phone for study?" / "Which apps do you use for class notes?" Bad: "Don't you agree phones are destroying students?" (leading) / "Do you like phones and also use laptops?" (double-barrelled).
  10. Less redundancy, easier search and update, better security and multi-user access, integrity constraints. (Any three.)

Section C — outline

  1. K-map 1s at m1, m3, m5, m7 form one group of 4 covering B=1 (or C=1 depending on labelling — with standard ABC order the 1s are all cells where C=1). F = C. Diagram: a single wire C to output (or a buffer). Show the map with the group circled.
  2. Pass 1: [1,4,2,5]; Pass 2: [1,2,4,5]; Pass 3: already sorted. Sorted [1,2,4,5]. Search 4: low=0 high=3 mid=1 (2<4) → low=2; mid=2 (4=4) found at index 2.
