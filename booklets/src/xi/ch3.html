3.1 Programming

Computers are "dumb" machines. They are very fast, but they cannot think or do anything on their own. They need exact, step-by-step instructions.

  • A set of instructions given to a computer is called a program.
  • The language used to write these instructions is called a programming language.
  • Writing programs is called programming, and the person who writes them is a programmer.

Think of a recipe. A cook follows the recipe line by line: "boil water, add rice, wait 15 minutes". A computer follows a program in the same way, one instruction at a time, without guessing what you meant.

A tiny program. Here is a complete Python program with one instruction. It tells the computer to show a message on the screen.

print("Hello")
Hello

The word print is the instruction; "Hello" is the data it works on.

Program = recipe, programmer = recipe writer, computer = cook who follows every line exactly. If the recipe is wrong, the food is wrong. The cook does not fix it for you.

Students often think the computer "understands" what they want. It does not. If you type Print("Hello") with a capital P, Python stops with an error, because it only knows print. Be exact.

Same task, three levels. Suppose you want to copy a value.

3.3 Integrated Development Environment (IDE)

An IDE (Integrated Development Environment) is a software tool that helps programmers write, run and manage code in one place. It is a complete workspace for programming. "Integrated" means many tools are joined together in one window.

Key features of an IDE:

  • Code Editor: where you write and edit code.
  • Syntax Highlighting: colours different parts of the code (keywords, strings, numbers) to make it easier to read.
  • Auto-completion: suggests code while you type (type pri and it offers print).
  • Run/Execute Tool: runs the program with one click.
  • Debugger: helps you find and fix errors, for example by pausing the program at a chosen line.

Without vs with an IDE. Without an IDE you would write code in Notepad, save it, open a terminal and type python file.py, then go back to Notepad to fix mistakes. With an IDE you write, run (press the ▶ Run button) and debug in the same window, and errors are underlined while you type.

IDE features — "E-S-A-R-D": Editor, Syntax highlighting, Auto-completion, Run, Debugger.

An IDE does not write the program for you and does not catch logical mistakes. It only makes writing, running and debugging easier.

3.4 Fundamentals of Python Programming ★ Golden

The basic structure of a Python program is simple and clear. A program takes data, processes it using statements, and finally shows output. Python runs the statements top to bottom, one after another (sequentially).

A statement is one complete instruction, usually written on one line, such as print("Hi") or x = 5.

1. Comments (#) — Comments are notes written in the code for humans. They start with the # symbol. The Python interpreter completely ignores them. Use them to explain what your code does.

2. Indentation (spaces) — C++ and Java use curly brackets { } to mark a block of code (a group of statements that belong together). Python instead uses indentation: spaces at the beginning of a line. Indentation is mandatory in Python. The standard is 4 spaces (or 1 tab).

# This is a comment. It explains the code below.
print("Hello, World!")
if 5 > 2:
    # The space before 'print' is the indentation
    print("Five is greater than two!")
Hello, World!
Five is greater than two!

Reading the program line by line:

  1. Line 1 starts with #, so Python skips it.
  2. Line 2 prints Hello, World!.
  3. Line 3 asks a question: is 5 greater than 2? The colon : says "a block follows".
  4. Line 4 is a comment inside the block (ignored).
  5. Line 5 is indented by 4 spaces, so it belongs to the if block. Because 5 > 2 is true, it runs.

What happens if you forget the indentation?

if 5 > 2:
print("Five is greater than two!")
  File "indent.py", line 2
    print("Five is greater than two!")
    ^
IndentationError: expected an indented block after 'if' statement on line 1

Python refuses to run the program and points to line 2. Add 4 spaces before print to fix it.

Think of indentation like the points and sub-points in your notebook. Sub-points are written a little to the right to show they "belong" to the main point. A colon : at the end of a line always means "indent the next line".

IndentationError? Check your spaces. Mixing tabs and spaces can break a Python program even when the code looks lined up. Choose 4 spaces and use them everywhere (VS Code inserts 4 spaces when you press Tab in a .py file).

3.4.1 Variables ★ Golden

A variable is a named space in computer memory used to store data. Think of it as a labelled container (a box with a name written on it). You put a value in it with the assignment operator =, which means "store", not "equals".

In Python you do not need to declare the type of a variable. Python figures it out automatically from the value. This is called dynamic typing: the same variable can later hold a different type.

Rules for naming variables:

  • Can contain letters, numbers and underscores (_) only — no spaces or symbols like -, @, $.
  • Must start with a letter or underscore, NOT a number (1name is invalid).
  • Are case-sensitive: age and Age are two completely different variables.
  • Cannot be a Python keyword (a reserved word such as if, for, while, else, True).

Valid names ✓

name = "Ali"
age = 16
my_height = 5.7
score1 = 100

Invalid names ✗

1name = "Ali"   # starts with a number
my height = 5.7 # contains a space
if = 100        # keyword used

Using variables and case-sensitivity:

Dynamic typing — the type follows the value. type() tells you the type:

x = 5

What Python says about an invalid name:

    1name = "Ali"
    ^

Choose meaningful names: total_marks is far clearer than tm or x. Use lowercase words joined by underscores (this style is called snake_case).

= is not "equals" in the maths sense. x = x + 1 is not a false equation; it means "take the value of x, add 1, and store the result back in x". To compare two values you use == (see 3.4.3).

3.4.2 Input and Output Handling

Output — the print() function. A function is a named, ready-made piece of code that does a job when you call it with brackets. print() displays information on the screen.

  • Items separated by commas are printed with one space between them.
  • An f-string (a string with f before the quote) lets you put variables directly inside { }. It is the fastest and most readable way to format output.

Input — the input() function. It shows a message (a prompt), pauses the program and waits for the user to type something and press Enter. Whatever the user types is always a string by default.

Type casting means converting a value from one type to another: int() converts to an integer, float() to a decimal number, str() to a string.

# 1. Print only a string
print("Hello Class!")

# 2. Print a string and a variable (comma separates them)
name = "Ali"
print("Welcome,", name)

# 3. f-strings (fastest and most readable way to format)
age = 16
print(f"My name is {name} and I am {age} years old.")
Hello Class!
Welcome, Ali
My name is Ali and I am 16 years old.

Two useful extras: sep changes the separator between items, and end changes what is printed at the end (normally a new line).

print("10", "09", "2026", sep="-")
print("Loading", end="...")
print("done")
print(f"Total: {7 * 3}")
10-09-2026
Loading...done
Total: 21

Taking input with type casting.

# Taking text input
user_name = input("Enter your name: ")
# Type casting: converting string input to an integer (int)
age = int(input("Enter your age: "))
# Type casting: converting string input to a decimal (float)
height = float(input("Enter your height: "))
print(f"Hello {user_name}! Next year you will be {age + 1}.")
print("Height:", height, "feet")

Why type casting matters. Without int(), the numbers stay as text and + joins them:

a = input("First number: ")
b = input("Second number: ")
print(a + b)
print(int(a) + int(b))
First number: 5
Second number: 3
53
8

"5" + "3" joins two strings into "53" (called concatenation). 5 + 3 adds numbers to give 8.

3.4.3 Bitwise Operators ★ Golden

6. Bitwise operators treat numbers as binary digits (bits: 0s and 1s) and work on them bit by bit, column by column. Think of each bit as a switch that is ON (1) or OFF (0). Python's bin() function shows the binary form of a number (it starts with 0b).

  • AND (&) — gives 1 only if both bits are 1, otherwise 0.
  • OR (|) — gives 1 if at least one bit is 1.
  • XOR (^) — gives 1 if the bits are different, 0 if they are the same.
  • NOT (~) — inverts all bits (0 → 1, 1 → 0). In Python the result is the number made negative, minus 1: ~x = -(x + 1). So ~10 gives -11.
  • Left shift (<<) — moves bits left and adds 0s on the right. Each shift multiplies by 2.
  • Right shift (>>) — moves bits right and removes the rightmost bits. Each shift divides by 2 (floor division).

3.5 Control Structures ★ Golden

Control structures decide the order in which statements are executed in a program (the "flow of control"). Almost every program is built from just three basic structures:

  1. Sequence — do the steps one after another, top to bottom.
  2. Selection — choose a path depending on a condition (if, else).
  3. Repetition — repeat steps (loops: for, while).

Morning routine as control structures:

  • Sequence: wake up → brush teeth → have breakfast.
  • Selection: if it is raining, take an umbrella; else take a cap.
  • Repetition: while the bus has not come, keep waiting.

Remember "S-S-R": Sequence, Selection, Repetition — "Step, Select, Repeat".

Selection and repetition both use conditions, but they are different: selection runs a block at most once; repetition can run a block many times.

3.5.1 Sequence

Sequence means statements are executed one after another, strictly from top to bottom, in the exact order they are written. This is the default behaviour of Python. No statement is skipped or repeated.

Order matters. A variable must be given a value before it is used. Using it first causes NameError: name '…' is not defined.

3.5.3 The while Loop, break and continue ★ Golden

2. The while loop repeats a block of code as long as a condition remains True. It is used when the exact number of iterations is not known in advance (for example, "keep asking until the password is correct").

A while loop needs three parts: (1) initialise a variable before the loop, (2) test the condition, (3) update the variable inside the loop. If you forget the update, the condition never becomes False and the loop never stops — an infinite loop.

Loop control statements change the normal flow of a loop:

  • break — exits (stops) the loop entirely and immediately.
  • continue — skips the rest of the current iteration and jumps to the next one.

3.5.3 Nested Loops and for vs while ★ Golden

A nested loop is a loop inside another loop. The inner loop runs completely, from start to finish, for every single iteration of the outer loop. If the outer loop runs 2 times and the inner loop runs 3 times, the inner body runs 2 × 3 = 6 times.

for outer in range(1, 3):        # runs 2 times (1, 2)
    for inner in range(1, 4):    # runs 3 times per outer (1, 2, 3)
        print(f"Outer: {outer}, Inner: {inner}")

Outer: 1, Inner: 3

Outer: 2, Inner: 3

A star triangle. The outer loop chooses the row; the inner loop prints that many stars on the same line (end=""), and the empty print() moves to the next line.

for row in range(1, 5):

3.7 Debugging Code in Python

Debugging is the process of identifying, tracing and fixing bugs so a program works correctly. Every program you write will have bugs. The skill is not "never make a mistake"; it is "find the mistake quickly".

Python errors fall into three families:

Examiners love "identify the error type" questions. Ask: (1) Does it refuse to start? → syntax. (2) Does it crash mid-run? → runtime. (3) Does it run but give a wrong answer? → logical. Write the name of the error and how to fix it.

Fix syntax errors first (the program cannot start). Then run it. Then check the output against a hand-worked example to catch logical errors.

A logical error is the most dangerous because Python reports nothing. Always test with values whose answer you already know (for a rectangle 3 by 4, area must be 12, not 7).

Short questions — model answers

  1. A compiler translates the whole program into machine code before it runs (C, C++). An interpreter translates and runs line by line (Python). Compiled programs often run faster; interpreted ones are easier to test.
  2. input() always returns a string. Adding strings concatenates them ("2"+"3" is "23"), so numeric work needs int() or float().
  3. / is true division: 17/5 is 3.4. // is integer (floor) division: 17//5 is 3.
  4. F and F → F; F and T → F; T and F → F; T and T → T. Output is True only when both operands are True.
  5. Python tests conditions from the top. The first True block runs and the rest are skipped. If you put marks >= 60 above marks >= 80, an 85 would match the weaker condition first and get the wrong grade.
