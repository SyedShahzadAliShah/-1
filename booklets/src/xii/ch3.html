3.1 Data Structures in Python

A data structure is a way of organising values in a program so you can store them, find them and change them. Every useful program is built on data structures. Python gives you two layers:

  • Primitive data structures — the basic types that hold one value. Examples: integers (int), floating-point numbers (float), and booleans (bool).
  • Abstract data structures — higher-level containers built from primitive types so you can hold many values and run richer operations. Examples: lists, tuples, sets, dictionaries.

Python has these four abstract structures built in. You do not install anything extra. That is why collecting marks, names or settings is simpler in Python than in many other languages.

Primitive = one piece. Abstract = a box of pieces. Think of a single rupee coin (primitive) versus a wallet that can hold many coins (list, tuple, set or dictionary).

Do not call a list a “variable type” and stop there. A list is a structure: it has an order, methods, and rules. The four abstract structures look similar at first (they all hold several values) but they follow different rules. Learn those rules one by one in 3.1.1–3.1.4.

3.1.1 Lists (Ordered, Mutable, Methods) ★ Golden

A list is Python’s most versatile built-in data structure. It stores an ordered collection of items in a single variable. Lists are mutable (you can change them after you create them) and they are written with square brackets [].

Why use a list? One variable can hold thousands of values. You can mix types if you need to. You can add, remove and sort items as the program runs.

numbers = [10, 2, 15, 14, 3, 33]        # list of integers
names = ["Hassan", "Qasim", "Malika"]     # list of strings
mixed = [1, "Python", 3.14, True]         # mixed data types
print(numbers)
print(names)
print(mixed)
[10, 2, 15, 14, 3, 33]
['Hassan', 'Qasim', 'Malika']
[1, 'Python', 3.14, True]

List indexing (positive and negative)

Each item sits in a numbered slot called an index. Numbering starts at 0 from the left. Python also supports negative indexing from the right: -1 is the last item, -2 is the second last, and so on.

fruits = ["apple", "mango", "banana", "grape", "kiwi"]
print(fruits[0])    # first item
print(fruits[4])    # last item (when you know the length)
print(fruits[-1])   # last item (works even if the list grows)
print(fruits[-5])   # first item, counted from the right

Slicing a list

Advantages of lists

  • Mutable — add, remove or replace items as the program runs.
  • Organised — thousands of values live in one variable instead of n1, n2, n3…
  • Flexible — integers, strings, booleans and even other lists can sit in the same list.

3.1.2 Tuples (Ordered, Immutable) ★ Golden

A tuple is an ordered collection that is immutable — once created, you cannot add, remove or replace items. Think of it as a read-only list. Tuples use parentheses (). Like lists, they allow duplicates, mixed types, and indexing from 0 (including negative indices).

t = (10, 20, 30, 40, 50)
print(t[0])
print(t[-1])
print(t[1:4])
print(t[::-1])
10
50
(20, 30, 40)
(50, 40, 30, 20, 10)

Slicing a tuple returns a new tuple, not a list. Negative indexing and [::-1] work exactly as they do for lists.

Immutability

You cannot assign to an index of a tuple. Python raises TypeError.

t = (1, 2, 3)
t[0] = 99
Traceback (most recent call last):
  File "tuple.py", line 2, in <module>
    t[0] = 99
TypeError: 'tuple' object does not support item assignment

Exception: if a tuple contains a mutable object (a list inside the tuple), that inner object’s contents can still change. The tuple still holds the same two list objects; you changed a list, not the tuple’s structure.

t = ([1, 2], [3, 4])
t[0].append(99)
print(t)
([1, 2, 99], [3, 4])

t[0] = [9, 9] would still be illegal, because that would replace the tuple’s first item. t[0].append(99) is legal because it mutates the list that already lives at index 0.

Traversal and methods

Traverse a tuple with for, just as you do a list. You are only reading, which is the usual reason to choose a tuple.

student = ("Ali", 20, "Computer Science")
for item in student:
    print(item)

3.1.3 Sets (Unordered, Unique, Math Operations)

A set stores an unordered, unindexed collection of unique elements. It is inspired by mathematical sets. You write a set with curly braces {}. Duplicates are removed as soon as the set is created. Because there is no index, myset[0] is illegal.

The set itself is mutable (you can add and remove items). Each item inside must be immutable (numbers, strings, tuples of immutables — not lists).

nums = {1, 4, 3, 3, 2, 2}
print(nums)
{1, 2, 3, 4}

The two 3s and two 2s collapse to one each. Do not depend on the printed order: a set is unordered. CPython often prints small integers in a tidy way, but that is not a language promise.

3.1.4 Dictionaries (Key-Value Pairs) ★ Golden

A dictionary stores data as key–value pairs. It works like a real dictionary: you look up a word (the key) to find its meaning (the value). Write a dictionary with curly braces, and put a colon between each key and value.

  • Ordered (Python 3.7+): insertion order is kept.
  • Mutable: you can add, change and delete pairs.
  • Keys are unique: if you repeat a key, the last value silently overwrites the earlier one. Values may repeat.

A school analogue: a roll number (key) can point to only one student (value). If you assign that roll number to someone else, the old link is gone.

Adding, changing and deleting

d = {"name": "Alice", "age": 30}
print(d)
d["age"] = 31
print(d)
d["city"] = "NYC"
print(d)
del d["city"]
print(d)

{'name': 'Alice', 'age': 31}

Assigning to an existing key updates the value. Assigning to a new key adds a pair. del d["city"] removes that pair.

The duplicate-keys rule. Python does not crash. The last assignment wins.

d = {"a": 1, "a": 2, "a": 3}
print(d)
{'a': 3}

1. Direct brackets (risky)

Same data, four structures. Three subject marks:

  • List [80, 70, 90] — easy to append a fourth test.
  • Tuple (80, 70, 90) — a frozen result slip.
  • Set {80, 70, 90} — unique scores only; two papers of 80 would become one 80.
  • Dictionary {"math": 80, "eng": 70, "cs": 90} — you ask “What is CS?” and get 90 without remembering an index.

Keys are unique, like roll numbers. Values are the student records and may repeat (two students can both score 80). Memory: “get is gentle, brackets can break.”

3.1.7 Activity: Word Frequency Counter

Count how many times each word appears in a sentence. This is a classic use of a dictionary plus .get(): the word is the key, the count is the value.

sentence = "python is easy python is fun python is powerful"

    word_freq[word] = word_freq.get(word, 0) + 1

    print(f"{word:<10} : {count}")

  1. sentence.split() cuts on spaces and gives
    ['python', 'is', 'easy', 'python', 'is', 'fun', 'python', 'is', 'powerful'].

  4. {word:<10} pads the word to 10 characters so the colons line up.
  5. max(word_freq, key=word_freq.get) picks the key whose value is largest. If two words share the top count, max returns the first of those keys in insertion order.

3.2 Functions in Python ★ Golden

When the same instructions are written again and again, that is duplicate code. Duplicate code makes a program longer, harder to read, and painful to update (you must fix every copy). A function lets you write the instructions once and run them whenever you call the function’s name.

BenefitMeaning
Code reusabilityWrite once, use anywhere.
ModularityBreak a big problem into small named tasks.
ReadabilityShorter, cleaner files with meaningful names.
MaintainabilityFix a bug in one place and every call is fixed.
def greet():
    print("Hello, World!")

greet()
greet()
Hello, World!
Hello, World!

The body is written once. Two calls run it twice. To change the message you edit one line inside greet.

Key components of a function

def→name→parameters→indented body→return (optional)
  • Keyword — Python uses def to start a definition.
  • Function name — the identifier you call, e.g. greet.
  • Parameters — input names inside the parentheses. When you call the function, the values you pass are called arguments.
  • Body — the indented block that runs on each call.
  • Return statement — sends a result back to the caller (3.2.2).
def add(a, b):
    print(f"Adding {a} + {b}")
    return a + b

result = add(4, 6)
print(result)
Adding 4 + 6
10

Here a and b are parameters. 4 and 6 are arguments. return a + b sends 10 back, and that 10 is stored in result.

Without a function you would copy the print-and-add lines every time you needed a sum. With a function, a new sum is one call: add(10, 20), add(1.5, 2.5).

DRY — Don’t Repeat Yourself. If you are about to copy-paste a block, wrap it in def. Name functions with verbs: greet, add, save_grades.

Defining is not calling. After def greet(): nothing prints until you write greet(). Forgetting the parentheses — writing greet alone — does not run the body. The body must be indented; a line at column 0 is outside the function.

3.2.2 Functions with Return Values

A function can either print a result (show it on the screen) or return a result (send it back to the caller). A returned value can be stored in a variable, printed later, or used in a further calculation. The call is replaced by the returned value, as if you had written that value in its place.

def multiply(a, b):
    return a * b

result = multiply(5, 3)
print("The answer is:", result)
The answer is: 15

multiply(5, 3) evaluates to 15. That 15 is stored in result.

Print versus return. This is the difference examiners want.

def show_sum(a, b):
    print(a + b)

def give_sum(a, b):
    return a + b

x = show_sum(2, 3)
print("stored from show_sum:", x)
y = give_sum(2, 3)
print("stored from give_sum:", y)
print("double it:", y * 2)
5
stored from show_sum: None
stored from give_sum: 5
double it: 10

show_sum prints 5 inside the function, then returns None (the default when there is no return). You cannot double that answer later. give_sum hands 5 back, so y * 2 is 10. Use print for messages; use return for results the rest of the program still needs.

return = send back; print = show now. return also exits the function immediately. Lines after return in the same function do not run.

Writing print(a * b) inside multiply and then result = multiply(5, 3) stores None in result, not 15. If you later write result + 1 you get TypeError. Return the number; let the caller decide whether to print it.

3.2.4 Scope of Local and Global Variables

Scope is the region of a program where a variable can be seen and used. Python has two scopes you must know for this chapter.

i) Local scope. A local variable is created inside a function. It exists only while that function is running. The main program cannot read it.

ii) Global scope. A global variable is created outside all functions. Any function may read it, and the main program can use it too.

Local — the name is invisible outside.

def calc():
    secret = 50
    print(secret)

calc()
print(secret)
50
Traceback (most recent call last):
  File "local_scope.py", line 5, in <module>
    print(secret)
NameError: name 'secret' is not defined

First the function prints 50. Then the main program tries print(secret) and fails: secret was born inside calc and died when calc finished.

Global — readable inside and outside.

x = 10

def show():
    print("Inside function:", x)

show()
print("Outside function:", x)
Inside function: 10
Outside function: 10

Assignment inside a function creates a new local with the same name. It does not change the global:

x = 10

def show():
    x = 99
    print("Inside:", x)

show()
print("Outside:", x)
Inside: 99
Outside: 10

Inside, x = 99 is a local. After the call, the global is still 10.

Local = inside the room; global = in the corridor. Everyone can see the corridor. Things left in a room are gone when you leave. Prefer locals. Too many globals make bugs hard to find because any function might be using them.

If you only read x inside the function, Python uses the global. If you assign to x anywhere in that function, Python treats x as local for the whole function. Mixing the two without care causes UnboundLocalError. Keep function inputs as parameters and outputs as return values instead of editing globals.

3.6 The with Statement (Context Manager) ★ Golden

It is easy to forget .close(). If the program crashes before .close() runs, the file may be incomplete or corrupted. Python’s with statement is a context manager: it opens the file, runs the indented block, and always closes the file when the block ends — even if an error occurs inside.

with open(...) as f→use f→block ends→file closed automatically
with open('myfile.txt', 'w') as new_file:
    new_file.write("Context managers are safe!\n")
# no .close() here — with already closed the file

After the indented block, new_file is closed. You do not write new_file.close().

3.8 Errors and Exceptions (Try-Except)

An exception is an error raised while the program is running — for example opening a file that is not there. Without handling, Python prints a traceback and stops. A try/except block catches the error and lets you show a clear message instead of crashing.

Error typeMeaning
FileNotFoundErrorThe path does not exist.
PermissionErrorThe operating system will not let you read or write that file.
IOErrorA general input/output problem (disk full, disk disconnected).

Put risky code in try. Put the recovery in except ErrorType. A final except Exception as e can catch anything else, using e as the error object.

try:
    with open('missing_data.txt', 'r') as f:
        content = f.read()
        print(content)
except FileNotFoundError:
    print("Error: The file does not exist. Please check the name.")
except Exception as e:
    print(f"An unexpected error occurred: {e}")
Error: The file does not exist. Please check the name.

  File "missing.py", line 1, in <module>
    open('missing_data.txt', 'r')

Professional software does not dump a red traceback on a user. If a file is missing or a disk fails, the user should see a calm sentence such as “Please check the file name” or “Please try again later.”

Do not wrap your entire program in one silent except: that ignores every mistake. You would hide real bugs. Catch the errors you expect, and keep the message honest. 'w' and 'a' create a missing file, so they do not raise FileNotFoundError; 'r' does.

3.9 Mini File Handling Project: Grade Tracker

This project uses 'w' to create a grades file, 'a' to add a student later, and 'r' to read every line and compute an average. It combines file handling, string methods and arithmetic.

Write names and marks ('w')→Append a new student ('a')→Read lines ('r')→Split, total, average
with open("grades.txt", "w") as f:
    f.write("Alice: 88\n")
    f.write("Bob: 75\n")
    f.write("Carol: 92\n")
print("Grades file created.")

with open("grades.txt", "a") as f:
    f.write("David: 81\n")
print("New student appended.")

with open("grades.txt", "r") as f:
    lines = f.readlines()
    total = 0
    for line in lines:
        name, grade = line.strip().split(":")
        print(f"{name} scored {grade}")
        total += int(grade)
    average = total / len(lines)
    print(f"\nClass average: {average:.1f}")

What happens in memory and on disk.

  1. 'w' creates grades.txt (or wipes an old one) with three lines.
  2. 'a' adds David: 81\n at the end. Alice, Bob and Carol stay.
  3. .readlines() returns
    ['Alice: 88\n', 'Bob: 75\n', 'Carol: 92\n', 'David: 81\n'].
  4. .strip() removes the trailing \n. .split(":") turns "Alice: 88" into ["Alice", " 88"].
  5. int(grade) accepts the extra space: int(" 88") is 88.
  6. Total = 88 + 75 + 92 + 81 = 336. Average = 336 / 4 = 84.0. The format :.1f prints one decimal place.

Same file, three modes, three with blocks. Never open the same file in 'w' when you only meant to add David — that would delete Alice, Bob and Carol.

Chapter 3 Review

Chapter summary

  • Python programs rest on primitive types (int, float, bool) and abstract structures: lists, tuples, sets and dictionaries.
  • A list is ordered and mutable, written with []. Index from 0; [-1] is last. Slice stop is exclusive. Methods include append, insert, remove, sort, reverse, clear.
  • A tuple is ordered and immutable, written with (). Item assignment raises TypeError. Only count and index exist as methods.
  • A set is unordered and unique, written with {}. Use | & - ^ for union, intersection, difference and symmetric difference. Prefer discard over remove.
  • A dictionary maps unique keys to values. d[key] can raise KeyError; d.get(key, default) is safe. Duplicate keys keep the last value.
  • min, max, len, sum and sorted work across structures. On a dict, min/max/sorted use keys; total values with sum(d.values()). sorted() returns a new list; .sort() changes a list in place.
  • Functions written with def give reusability, modularity, readability and maintainability. Built-in functions already exist; user-defined functions solve your tasks.
  • return sends a value to the caller. Without return, the result is None. Local variables live inside a function; global variables live outside all functions.
  • Files persist on disk. Modes: r read (must exist), w write (overwrites), a append. Methods: read, readlines, write, close.
  • The with statement is a context manager that closes the file automatically. Loop line by line to read large files safely.
  • try/except FileNotFoundError stops a missing file from crashing the program.
  • The grade tracker writes with w, appends with a, reads with r, splits each Name: mark line, and computes the mean.
