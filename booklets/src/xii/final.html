Chapter 1 recap — Human Computer Interaction

  • HCI = study of how people and computers work together so systems are usable, useful and satisfying.
  • Traditional interaction = keyboard, mouse, menus. Natural interaction = touch, voice, gesture, gaze.
  • Components: user, computer, interaction (input + output + feedback) inside an environment.
  • UI = how it looks and the controls. UX = how the whole experience feels. Wireframe → prototype (Figma) → test.
  • Evaluate with usability tests, heuristic evaluation, A/B tests and automated checks. Golden: accessibility, HCI problems, UI vs UX, testing methods.

Chapter 2 recap — Algorithms and Data Structures

  • Correctness: trace table (variable values after every step) or stepwise reasoning.
  • Clarity: modularity (small named parts) and readability (names, comments, indentation).
  • Efficiency: count steps, conditions, repetitions. Big O: O(1) constant, O(log n) binary search, O(n) linear, O(n log n) good sorts, O(n²) nested loops.
  • Linear DS: array, linked list, stack (LIFO, push/pop), queue (FIFO, enqueue/dequeue). Non-linear: tree (one root, parent-child), graph (nodes + edges).
  • Pick the structure from the problem: undo → stack; printer jobs → queue; hierarchy → tree; maps → graph; fast index → array.

Chapter 3 recap — Python Data Structures, Functions and Files

  • list [] ordered, mutable. tuple () ordered, immutable. set {} unordered, unique. dict {k:v} key-value, mutable.
  • Functions: def, parameters, return. Local vs global scope. Built-in vs user-defined.
  • Files: "r" read, "w" overwrite, "a" append. Always prefer with open(...) as f so the file closes itself.
  • Exceptions: try / except / else / finally. Catch specific errors (ValueError, FileNotFoundError).

Chapter 4 recap — Data and Analysis

  • SQLite in Python: connect → cursor → execute → commit → close. Always commit writes.
  • Pandas DataFrame = table. load CSV/Excel, isnull, dropna, fillna, sort, filter, groupby.
  • Charts: bar (categories), line (trend over time), pie (parts of a whole, few slices), histogram (distribution), scatter (relationship of two variables), box (spread and outliers).
  • Mean = average. Median = middle after sorting. Mode = most frequent. Range = max−min. Variance / std-dev measure spread. pandas .std() uses sample n−1.

Chapter 5 recap — AI, Security and Collaboration

  • AI ⊃ Machine Learning ⊃ Deep Learning. A neuron: weighted sum + bias, then an activation function. Deep = many hidden layers.
  • Secure collaboration: authentication (passwords, MFA), access control (who may do what).
  • Protect data: encryption, strong passwords, 3-2-1 backup, firewall. Threats: malware, phishing, DoS/DDoS, social engineering.
  • Equity: everyone can take part (devices, language, disability, bandwidth). Tools: shared docs, video, LMS, versioning.

Chapter 6 recap — Entrepreneurship in the Digital Age

  • Entrepreneur = person who turns a problem into a venture, taking risk. Digital tools make testing cheap (WhatsApp, Forms, a Facebook page).
  • Prototype = experimental model. Low / mid / high fidelity. Cycle: Design → Build → Test → Iterate.
  • MVP = smallest product that tests the riskiest assumption with real users. Prototype ≠ MVP (MVP is used in the real market).
  • Beachhead market = the first, narrow group you can win. Measure retention, not only sign-ups. Use data ethically.

Section B

  1. UI is the screens and controls (buttons, colours). UX is the whole journey (time to complete a task, frustration, trust). Example: a JazzCash send-money screen (UI) vs how safe and quick the payment felt (UX).
  2. A trace table lists each variable after every instruction. It proves correctness on a chosen input; "it looks right" misses off-by-one and uninitialised variables.
  3. After push 10, TOS=10. After push 20, TOS=20 (10 below). After pop, 20 removed, TOS=10.
  4. list: ordered mutable. tuple: ordered immutable. set: unordered unique. dict: keyed pairs.
  5. def area(l, w): return l * w then print(area(3, 4)) → 12.
  6. connect, cursor, execute, commit, close.
  7. Scatter: two measured variables (height vs marks) with no single time axis. Line: one quantity changing over an ordered time or sequence.
  8. Sorted: 2,4,6,8,10. Mean = 30/5 = 6. Median = 6. Range = 10−2 = 8.
  9. Unknown sender, urgent threat ("account will close today"), a link that does not match the real bank, request for OTP/password, poor Urdu/English, unexpected attachment.
  10. A prototype is a model used to learn (often internal). An MVP is a real, usable product with just enough features to test the riskiest assumption with actual customers.
