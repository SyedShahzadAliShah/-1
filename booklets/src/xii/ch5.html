5.1 Machine Learning, Neural Networks and Deep Learning

Machine learning (ML), neural networks (NN) and deep learning (DL) are important areas of artificial intelligence (AI). AI is the broad field in which computers perform tasks that normally need human thinking, such as recognising a face, understanding speech or making a decision.

These technologies help computers learn from data and make useful decisions without being explicitly programmed for every single step. You do not write a separate rule for every possible face or every Urdu accent. You show the computer many examples, and it finds the patterns itself.

They are used in many modern systems:

  • Face unlock on smartphones.
  • Speech recognition (for example Siri, Alexa, or Urdu voice typing on a phone).
  • Photo search categorisation (typing “car” in a gallery and seeing car photos).
  • Medical diagnosis from X-rays and scans.
  • Language translation (English to Urdu or Sindhi).

Remember the nesting: AI is the biggest set. Inside AI sits ML. Inside ML sits DL. Every deep-learning system is a kind of machine learning, and every machine-learning system is a kind of AI — but not every AI system is deep learning.

Worked example: place each system in the correct set. Sara in Karachi uses three features on her phone.

  1. A chess app that follows fixed if-then rules written by a programmer (“if the queen is attacked, move it”). This is AI (the machine decides), but it is not ML, because it does not learn from data.
  2. A JazzCash fraud filter that was trained on thousands of past transactions and then flags a new unusual payment. This is ML (and therefore also AI). If it uses only a simple model with few layers, it may not be DL.
  3. Face unlock that studied millions of face images through many hidden layers. This is DL — and therefore also ML and AI.

Exam sentence you can write: All DL is ML, all ML is AI, but not all AI is ML, and not all ML is DL.

Russian-doll memory trick. Picture three boxes. The outer box is AI. Inside it is a smaller box ML. Inside that is the smallest box DL. You cannot take DL out of ML, and you cannot take ML out of AI.

Mistake: “AI, ML and DL are three different, separate subjects.”

Fix: They nest. DL ⊂ ML ⊂ AI. A deep-learning face-unlock system is all three at once.

5.1.1 Machine Learning (ML)

A machine learning model is the system that learns from data and gives an output. Think of it as the trained brain of a computer program.

In ordinary programming you write every rule yourself: if marks ≥ 40 then “Pass”. In machine learning you do not list every rule. You give the model many examples (data), it finds the patterns, and later it decides about new cases it has never seen.

How it works — three steps:

1. Data input→2. Learning (find patterns)→3. Prediction on new data
  1. Data input. The model is given massive amounts of data — for example thousands of past BISE marksheets, or millions of crop photos from Sindh fields.
  2. Learning. It studies the data and learns patterns and rules automatically. It might notice that students who scored low in Chapter 3 also failed the board exam, or that yellow spots on cotton leaves often mean a pest.
  3. Prediction. After training, it can make accurate predictions or decisions when given new, unseen data — a new student’s record, or a new leaf photograph.

Note from the source: there are many types of machine-learning models. A neural network is one important type. Deep learning is a highly advanced method of machine learning.

Worked example: a wheat-yield model for a farm near Sukkur.

Step 1 — Data input. For 8 years the farm recorded: rainfall (mm), temperature, fertiliser bags used, and the actual yield (maunds per acre).

Step 2 — Learning. The model studies those rows. It finds, for example, that yield rises with fertiliser up to a point, and falls when temperature is very high in April.

Step 3 — Prediction. This year the farmer types in this season’s rainfall and temperature. The model has never seen this exact year before, but it predicts “about 32 maunds per acre.” The farmer plans storage and a buyer in advance.

Nobody wrote a giant list of “if rain = 120 and temp = 38 then yield = …”. The model learned the pattern from data.

D-L-P. Machine learning is Data in, Learn patterns, Predict. “Data Learns to Predict.”

Mistake: “The computer is intelligent on day one.”

Fix: An ML model is useful only after training on enough good data. Garbage data → garbage predictions. Also, neural networks are one type of ML, not the only type; deep learning is a method that uses deep neural networks.

5.1.2 Neural Networks (NN) ★ Golden

A neural network is a computer model that learns patterns from data. It is directly inspired by the human brain, but it works as a mathematical computer system — not as living tissue.

Your brain has billions of nerve cells (neurons) that pass signals to each other. A neural network copies this idea with small processing units also called neurons or nodes. These nodes are connected and pass information from one layer to another, performing calculations at each step.

A typical neural network has three kinds of layer:

  • Input layer — receives the raw data (pixels of a face, samples of a sound, marks of a student).
  • Hidden layer(s) — the “thinking” in the middle. Nodes here combine the inputs and learn features (eye distance, nose shape, an edge in a photo).
  • Output layer — gives the final answer (unlock / keep locked; “this is a cat”; “pass / fail”).
Input layer→Hidden layer(s)→Output layer

Practical example from the source: face unlock.

Step 1 — Input layer. You look at your phone. The camera captures your face as numbers (brightness of each pixel). Those numbers enter the input layer.

Step 2 — Hidden layers. The system studies face features such as eye distance and nose shape. Early hidden nodes may detect edges and shadows; later hidden nodes combine those into “this looks like Sara’s face.” It compares them with stored data from when you first set up the phone.

Step 3 — Output layer. If the features match, the phone unlocks. If they do not (your brother holds the phone), it stays locked.

The same three-layer story works for an NADRA-style biometric gate at a college: camera (input) → feature matching (hidden) → open the turnstile or not (output).

I-H-O. Input receives, Hidden thinks, Output decides. “In Hidden Out.” A neural network is a brain-inspired maths machine, not a copy of a living brain.

Mistake: “A neural network is an actual human brain inside the computer.”

Fix: It is only inspired by the brain. It is mathematics: numbers, multiplications and additions running on ordinary hardware.

5.1.3 Deep Learning (DL)

Deep learning is a machine-learning method in which computers use multi-layer neural networks to learn complex patterns from data.

The word “deep” is used because data passes through several hidden layers before the system produces the final output. Each layer learns a different level of detail:

  • Early layers learn simple features — edges, shapes, colours.
  • Deeper layers combine those simple features to understand complex patterns — a whole face, or a specific car model (a Cultus versus a Corolla).

A network with only one or two hidden layers is a shallow neural network. Deep learning is always “deep”: it needs huge amounts of data and processing power.

Neural network vs deep learning

Neural network (the model)Deep learning (the method)
What it isA system/model that has layers, nodes and connections to help it learn.A specific method that trains neural networks containing many hidden layers.
DepthCan be simple (shallow) with just one or two hidden layers.Always “deep,” requiring huge amounts of data and processing power to learn complex patterns.
RoleThe architecture (the “machine”).The way we train a deep version of that machine.

Real-world example from the source: photo gallery search.

A modern gallery app on a smartphone uses deep learning to recognise faces, objects or places in thousands of photos.

Step 1. During training (done by the company, using millions of images) early layers learned edges and colours; deeper layers learned “wheel”, “petal”, “minaret”.

Step 2. The trained network has already scanned your phone’s photos and tagged them.

Step 3. You type “car” or “flower” in the search bar. The app instantly shows related photos because its deep neural network has already learned visual patterns from millions of training images.

A student in Hyderabad can type “Ajrak” or “cricket” and jump to those pictures without scrolling for ten minutes.

Deep = many hidden layers. Shallow NN: 1–2 hidden layers. Deep NN: many hidden layers, huge data, strong computers. Simple features first, complex meaning later.

Mistake: “Deep learning and neural networks are two names for the same thing.”

Fix: A neural network is the model (layers + nodes + connections). Deep learning is the method of training networks that have many hidden layers. A small NN with one hidden layer is not deep learning.

5.1.4 Components of Neural Networks ★ Golden

The components of a neural network can be understood through its layered architecture. Data enters, gets processed, and exits, with mathematical adjustments happening inside.

#ComponentDescription
1Input layerReceives the initial raw data (for example image pixels, sound waves, text).
2Neurons / nodesSmall processing units that receive, calculate, and pass information forward.
3Hidden layer(s)The layers between input and output. They process the data and learn patterns from it.
4WeightsNumbers that show the importance or strength of connections between neurons.
5BiasAn extra constant value added to help the model adjust its result and improve accuracy.
6Activation functionA mathematical gate that decides whether the information is important enough to move to the next layer.
7Output layerGives the final computed result, decision or prediction (for example “This is a cat”).
8Loss functionChecks the error (how much the model’s answer is wrong compared with reality) so the network can correct itself.

What happens inside one neuron

Each neuron does a short calculation:

  1. Multiply each input x by its weight w.
  2. Add those products together, then add the bias b. This total is the weighted sum s.
  3. Pass s through an activation function. A simple exam-friendly gate is a threshold (step) function: if s is at least the threshold, the neuron fires (output = 1); otherwise output = 0.

In symbols: s = (x1 × w1) + (x2 × w2) + … + b, then y = 1 if s ≥ threshold, else y = 0.

Worked example: neuron calculation with numbers. A college in Larkana uses a tiny network to guess whether a student is ready for a test. One hidden neuron receives two inputs:

SymbolMeaningValue
x1Hours studied yesterday (scaled 0 to 1)0.8
x2Attendance this month (scaled 0 to 1)0.5
w1Weight of hours studied0.4
w2Weight of attendance0.6
bBias0.1
thresholdActivation gate0.5

Step 1 — weighted products.

x1 × w1 = 0.8 × 0.4 = 0.32

x2 × w2 = 0.5 × 0.6 = 0.30

Step 2 — add bias to get the weighted sum s.

s = 0.32 + 0.30 + 0.1 = 0.72

Step 3 — activation (threshold 0.5). Is 0.72 ≥ 0.5? Yes, so the neuron fires: y = 1 (ready for the test).

Step 4 — a second student with x1 = 0.2 (almost no study) and x2 = 0.3:

s = (0.2 × 0.4) + (0.3 × 0.6) + 0.1 = 0.08 + 0.18 + 0.1 = 0.36

0.36 is less than 0.5, so y = 0 (not ready). The same neuron, different inputs, different decision.

Loss function, briefly. If the true answer for the first student was actually “not ready” (true y = 0) but the model said 1, the loss is high. Training then slightly changes weights and bias so the next guess is closer to reality.

Weights = importance. Bias = extra nudge. Activation = yes/no gate. Loss = how wrong. A large weight means that input matters more. Bias shifts the sum up or down so the gate can open at the right place.

Mistake: Forgetting to add the bias, or multiplying instead of adding after the products.

Fix: Always multiply first (each x by its w), then add the products, then add b, then apply the activation. Write the four lines in the exam as we did above.

5.1.5 Components of Deep Learning

Deep learning relies on specific advanced components to achieve its high accuracy. These components differentiate it from basic machine learning.

#ComponentWhat it means
1Large input dataDeep learning is “data hungry.” It needs massive datasets (thousands or millions of records) for better learning and accuracy.
2Many hidden layersUses dozens or hundreds of hidden layers to learn deeper, more intricate patterns.
3Automatic feature learningUnlike older models where humans had to manually highlight important features, deep learning extracts important features by itself.
4Learning algorithmMath routines (like backpropagation) that help the system reduce mistakes and improve learning continuously.
5High computing powerProcessing millions of data points across deep layers needs specialised, strong hardware, such as GPUs (Graphics Processing Units).
6Training processThe model is trained again and again in loops called epochs to gradually improve its final performance.

A GPU was originally made for video games’ graphics, but it can do thousands of small multiplications in parallel — exactly what deep networks need. An epoch is one full pass through the training data. Ten epochs means the model has seen every training example ten times, adjusting weights a little each time.

Backpropagation means sending the error (from the loss function) backwards through the layers so each weight can be nudged in the direction that reduces the next error.

Worked example: cotton-leaf disease detector for a farm in Mirpurkhas. Match each DL component.

  1. Large input data. Researchers collect 80,000 labelled photos: healthy leaves and leaves with whitefly damage.
  2. Many hidden layers. The network has 20 hidden layers so it can go from “green edge” to “this exact pest pattern.”
  3. Automatic feature learning. No agronomist types in “look for yellow circles.” The network finds the useful spots itself.
  4. Learning algorithm. After a wrong guess (“healthy” when it was diseased), backpropagation lowers the weights that caused the mistake.
  5. High computing power. Training runs on a GPU workstation at a university lab in Karachi; a school laptop would take weeks.
  6. Training process. They train for 30 epochs. After epoch 1 accuracy is 62%; after epoch 30 it is 94% on photos it has not trained on.

D-L-A-L-G-T. Data (lots), Layers (many), Automatic features, Learning algorithm, GPU power, Training epochs. “Deep Learners Always Love Good Training.”

Mistake: “Deep learning is just ‘a neural network’.”

Fix: Name the six extras: huge data, many hidden layers, automatic features, a learning algorithm (backpropagation), GPUs, and repeated epochs. A shallow NN with a small spreadsheet is ordinary ML, not DL.

5.3.1 Secure Collaboration (Authentication, MFA, Access Control) ★ Golden

Digital tools allow people to share files, attend online classes, edit documents and work together from different locations. Collaboration is useful only when data is protected and communication remains safe.

Secure collaboration means using digital tools to work together in a safe, controlled and responsible way. It depends on several key elements.

i) Authentication / identity verification

Authentication is confirming the identity of a user before allowing access. Common methods:

  • Username and password
  • PIN (a short number code)
  • OTP — One-Time Password, a code that works only once, usually sent by SMS or an authenticator app
  • Biometrics — fingerprint or face

Source example: a banking app sending an OTP to your phone before login.

Multi-factor authentication (MFA) and two-factor authentication (2FA)

A factor is a category of proof:

  • Something you know — password or PIN.
  • Something you have — your phone, an OTP, a bank SMS.
  • Something you are — fingerprint, face (biometrics).

Multi-factor authentication (MFA) means the system asks for two or more different factors before it trusts you. Two-factor authentication (2FA) is the common case of MFA that uses exactly two factors — usually password + OTP.

If a thief in another city steals only your password, MFA still blocks them because they do not have your phone (or your fingerprint).

ii) Access control

Access control decides what an authenticated user is allowed to do: View, Edit, Comment, Download, Share.

Authentication answers “Who are you?” Access control answers “What may you do?”

Source example: a teacher shares a Google Doc with students as “view only”, but gives group leaders “edit” permissions.

iii) Accountability and tracking

User actions are linked to verified accounts. You can see who opened, edited, deleted or shared a file. Example: a school LMS (Learning Management System) tracks which teacher uploaded an assignment and which student submitted it.

iv) Data privacy

Data privacy means protecting personal and sensitive information and using it only for the purpose it was collected. It involves:

  • Protection — keeping names, numbers, marks and passwords secure.
  • Controlled sharing — sharing only with the right people.
  • Confidentiality — data stays private during storage and transmission.
  • Compliance — following legal and ethical rules for data handling.

v) Safe communication / transmission

Exchanging information through digital platforms securely, protecting messages from unauthorised interception or wiretapping. Example: a teacher shares class instructions through an official, encrypted LMS rather than an open public forum or an unknown WhatsApp broadcast.

Worked example: a Class XII Google Classroom in Sukkur.

Step 1 — Authentication. Each student signs in with a school email and password. The college turns on MFA: after the password, Google sends an OTP to the student’s registered Jazz/Zong number.

Step 2 — Access control. All 40 students can view the assignment sheet. Only the four group leaders can edit the shared report. Nobody except the teacher can delete the class materials. A student who left the college is removed from the class (access revoked).

Step 3 — Accountability. Version history shows that Ali edited paragraph 2 at 8:14 pm and that Hina submitted the PDF at 9:02 pm.

Step 4 — Privacy and safe transmission. Marks stay inside Classroom; the teacher does not post CNIC numbers or phone numbers in a public Facebook group. Traffic to Google is encrypted, unlike an open public forum.

If Ali shares his password with a cousin, authentication is broken. If the teacher gives every student “edit” on the marksheet, access control is broken even though login still works.

A-A-A-P-S. Authentication, Access control, Accountability, Privacy, Safe transmission. MFA = at least two different factor types (know / have / are). 2FA is MFA with two factors.

Mistake: Treating authentication and access control as the same thing.

Fix: Login only proves identity. After login, access control still limits View / Edit / Comment / Download / Share. A student who is authenticated must not automatically get teacher rights.

5.3.2 Data Protection (Encryption, Passwords, Backup, Firewall)

Data protection means keeping digital information safe from unauthorised access, misuse, loss, damage or accidental deletion.

1. Data encryption

Encryption changes readable data (plaintext) into a coded form called ciphertext. Unauthorised users cannot understand ciphertext without the key.

  • Symmetric encryption — the same key is used to encrypt and to decrypt.
  • Asymmetric encryption — two keys: a public key to encrypt, a private key to decrypt.

A simple exam cipher is the Caesar cipher (a symmetric substitution cipher). You shift every letter a fixed number of places along the alphabet. Shift 3 is the classic key: A → D, B → E, …, Z → C (the alphabet wraps around).

2. Strong passwords

A strong password includes uppercase, lowercase, numbers and symbols. It resists brute-force guessing (trying every possible combination). Source example: Zk@2026#Pass.

Weak: ahmed123, pakistan, sindh, your date of birth. Never reuse the same password on the college LMS and on JazzCash.

3. Backup and recovery — the 3-2-1 rule

A backup is a copy of data in a safe location (cloud or external drive) so you can restore it after hardware damage, ransomware or accidental deletion.

The 3-2-1 backup rule is a practical standard:

  • 3 copies of the data (the original plus two backups).
  • 2 different types of storage media (for example laptop disk + USB, or disk + cloud).
  • 1 copy off-site (a different building or the cloud), so a fire or theft at home does not destroy every copy.

4. Firewall and antivirus software

A firewall is a security barrier that monitors network traffic and blocks suspicious internet access. Think of it as a checkpoint on the road between your device (or college lab) and the internet.

Antivirus software detects and removes harmful software (viruses, spyware and other malware) from the local machine.

Firewall ≈ guards the door to the network. Antivirus ≈ searches inside the house for intruders already present.

Worked example A — Caesar cipher, shift = 3. Encrypt the plaintext SINDH, then decrypt the result.

Write the alphabet and count three letters forward. Wrap after Z back to A.

def caesar(text, shift):
    result = ""
    for ch in text:
        if ch.isalpha():
            base = ord("A") if ch.isupper() else ord("a")
            result += chr((ord(ch) - base + shift) % 26 + base)
        else:
            result += ch
    return result

A security threat is any action, event or weakness that can harm a computer system or its data. Mitigation techniques are protective measures used to prevent threats or reduce their impact. This section names the common threats; later sections show how to spot them and how to reduce the damage.

5.5 Equity and Equal Access in Digital Collaboration

Collaboration tools are vital for online learning and teamwork. To use these tools fairly, all users must participate without barriers. You must understand the difference between equal access and equity.

Equal access

Giving everyone the exact same opportunity, tools and resources.

Example: providing every student with the same login ID to access a Zoom class.

Equity

Giving additional, specific support to users who need it, so they can reach the same outcome.

Example: turning on live subtitles/captions in Zoom specifically for a student who has hearing difficulties.

Equal access is the same starting kit. Equity is extra help so a person who faces a barrier can still finish the race with everyone else. Fair collaboration needs both: the same Zoom link for all (equal access) and captions, recorded lectures or a low-data app where needed (equity).

Worked example: one class, two ideas. A teacher in Thatta starts online classes.

Equal access: every student receives the same Zoom ID and password. That is fair in the sense of “same tool,” but a student with hearing loss still cannot follow the spoken lecture, and a student in a village with a weak 2G signal cannot join video.

Equity: the teacher turns on captions, posts a low-size audio recording, and accepts the assignment as a Google Doc in the browser (not only through a heavy app). Now those two students can reach the same learning outcome.

Equal = same tools. Equity = extra support for the same outcome. Same shoes for all vs a ramp for the wheelchair user.

Mistake: “We gave everyone the same login, so the class is fair.”

Fix: Same login is equal access only. If some students still cannot hear, see, afford a smartphone, or get electricity, you still need equity.

Chapter 5 Review

Chapter summary

  • ML is a model (a trained brain) that learns from data in three steps: input, learning, prediction on new unseen data — without a hand-written rule for every case.
  • AI ⊃ ML ⊃ DL: deep learning sits inside machine learning, which sits inside artificial intelligence.
  • A neural network is a brain-inspired mathematical model of connected neurons in an input layer, hidden layer(s) and output layer (face unlock: camera → features → unlock).
  • Deep learning trains neural networks with many hidden layers; early layers learn simple features, deeper layers learn complex patterns. It needs huge data and computing power.
  • NN components: input layer, neurons, hidden layers, weights, bias, activation function, output layer, loss function. A neuron computes s = Σ(x × w) + b, then an activation gate.
  • DL components: large data, many hidden layers, automatic feature learning, learning algorithm (backpropagation), GPUs, training epochs. Pakistan’s National AI Policy 2025 covers education, health, agriculture, banking and local languages.
  • Applications: image and speech recognition, NLP, healthcare imaging, recommendations, autonomous vehicles, fraud detection, assistive tech.
  • Secure collaboration: authentication (who), MFA/2FA (two or more factors), access control (what you may do), accountability, privacy, safe transmission.
  • Data protection: encryption (plaintext → ciphertext; symmetric vs asymmetric; Caesar shift), strong passwords, 3-2-1 backup, firewall and antivirus.
  • Threats: malware, phishing, unauthorised access, data/identity theft, DoS, human error. Spot them by pop-ups, odd logins, urgent OTP emails, missing files, traffic spikes.
  • Mitigation: antivirus + firewall, strong passwords + 2FA, encryption, regular backups, user awareness.
  • Equal access = same tools for all; equity = extra support for the same outcome. Functions: need-based support, removing barriers, recorded participation, multiple formats. Tools: Docs, Zoom, Teams, Classroom/LMS, WhatsApp, email.
