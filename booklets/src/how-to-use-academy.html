How to run this Coaching Academy Edition

This book is for a coaching academy batch (not a 40-minute school period). A standard academy class is 90 minutes. Golden topics (★) get a full class. Other topics pair into one class. After the last class of a chapter, sit the thorough 75-mark closed-book exam (15 MCQ + 10 short + any 3 long). Every topic has a full-mark recipe, an academy drill with answers, and batch homework.

The 90-minute academy class

  1. 0–10 min — Starter test. Three oral or written 1-mark questions from last class. Marks go in the batch register.
  2. 10–35 min — Concept lock. Write the definition, table and diagram on the whiteboard. Students copy. No phones.
  3. 35–55 min — Board working. Do the worked example. Then hide it. Two students redo it on the board.
  4. 55–75 min — Academy drill. Timed. 1-mark then 3-mark then 5-mark. Mark at once with the recipe in this book.
  5. 75–85 min — Error clinic. Collect the three most common wrong answers. Correct them in one box on the board.
  6. 85–90 min — Homework out. One 5-mark question + one drawing/code/trace. Collect next class and mark to the scheme.

How academy answers score marks

  • 1 mark: one exact definition or one named fact.
  • 2 marks: definition + one example (preferably local: JazzCash, school portal, NADRA, load-shedding).
  • 3 marks: definition + two clear points + example.
  • 5 marks: definition, a four-point table or explanation, example, and a labelled diagram if the topic has one.
  • 8–10 marks: 5-mark structure + full working (trace, K-map, code, ER diagram) + a one-line conclusion.

Train this wording in every class: Define. Explain. Example. Diagram. Working. Examiners award method marks. An answer with no working is a half-answer.
