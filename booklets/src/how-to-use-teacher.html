How to use this Teacher's Edition

This book is for the teacher. Every topic has a Teacher notes box: suggested minutes, questions to ask the class, a board cue, an Urdu classroom line, and the Check yourself answers in place. Golden topics (★) need a full period. Practice papers may be homework or a timed test.

A 40-minute period

  1. 0–5 min. Recap yesterday with two oral questions from the last Check yourself.
  2. 5–25 min. Teach the Learn it points on the board. Students copy the table or diagram.
  3. 25–32 min. Worked example: you start it, the class finishes it.
  4. 32–38 min. Check yourself asked orally. Do not skip Golden topics.
  5. 38–40 min. Set one short question or the next topic's preview as homework.
