How to use this Lecture-Notes Study Guide

This booklet is the classroom photocopy pack. Each topic is one note: the board definition, the points you copy, one table or diagram, the exam wording, and one Urdu line. It is not a textbook. Open the Student's Edition for worked examples.

یہ کلاس روم کے لیکچر نوٹس ہیں۔ بورڈ پر تعریف لکھیں، نکات نقل کریں، جدول بنائیں۔ مثالیں اصل کتاب میں ہیں۔

A 40-minute period

  1. 0–5 min. Recite yesterday's ★ Golden definition. Redraw its table from memory.
  2. 5–25 min. Teacher writes the Board line. Students copy the numbered points and the table or diagram. Golden topics first.
  3. 25–35 min. Books closed. Say the definition. Redraw the table. Mark at once from the note.
  4. 35–40 min. Set one 5-mark: Define · Explain · Example · Diagram · Working.

If the period is short: teach only the ★ Golden notes. Never skip the closed-book five minutes.

What each note holds

  • Board — the 1-mark sentence you write on the whiteboard.
  • Points — the 3-mark and 5-mark body.
  • Table / diagram / snippet — copy this exactly.
  • Remember / Exam — mnemonic and how the board asks it.
  • اردو — the same idea in one spoken line.

★ Golden notes are high-yield. Teach them first in every chapter.
