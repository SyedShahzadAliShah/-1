How to use this booklet

This booklet is written so that you can learn every chapter on your own, without a teacher sitting next to you. Each topic explains the idea in simple English, shows a worked example, gives you a memory trick, warns you about common mistakes, explains it again in Urdu, and ends with quick questions so you can check that you really understood.

The 5-step self-study method

  1. Preview (5 minutes). Read the chapter opener and the "What you will learn" list. Turn each objective into a question you want answered.
  2. Learn one topic at a time. Each topic is printed on a single A4 page. Read the explanation, then work through the example with a pen and paper. Do not just read the solution — reproduce it.
  3. Check yourself straight away. Answer the "Check yourself" questions from memory. If you get one wrong, re-read that topic before moving on.
  4. Sit the chapter exam. After the last topic, read the recap, then sit the closed-book paper (75 marks: 15 MCQ + 10 short + any 3 long, 1 hour 15 minutes). Mark only after time is up.
  5. Review and repeat. Tick the "I can…" checklist. Revisit anything you could not tick after 1 day, 3 days and 7 days. Spaced repetition makes knowledge stick.

Tips for board exam answers

  • Define, explain, example. A strong short answer gives a clear definition, one or two lines of explanation and a real-life example.
  • Use tables for "differentiate" questions. Compare at least four points side by side.
  • Draw and label. Logic gates, diagrams, charts and data structures earn marks when drawn neatly and labelled.
  • Show every step. In K-maps, sorting traces, trace tables, statistics and code output questions, examiners give marks for the working, not only the final answer.
  • Write correct code. Indent Python carefully, use meaningful variable names, and write the expected output under your program.
