extract useful information. In real life, organizations use data analysis to make
decisions, identify trends, and solve problems.
Schools: Analyze student results to improve academic performance.
Businesses: Analyze sales data to increase profits and understand customer
behavior.
Hospitals: Analyze patient records to improve diagnosis and treatment.
Why use Python for Data Analysis?
Python is one of the most popular programming languages for data analysis
because it is simple, advanced, and supports powerful external libraries.
It can read data from different sources such as files (CSV/Excel) and databases.
It can organize data into structured formats.
It performs complex statistical calculations effortlessly.
It creates beautiful visual representations like graphs and charts.
💡 Real-World Perspective
Python acts as a bridge between the mathematical concept of data
analysis and its real-world implementation, allowing users to write 5 lines of
code to do what would take hours in traditional spreadsheet software.

4.1.1 Data Sources and Need for Connectivity
Data sources are the origins of information used for processing and analysis
(e.g., schools, websites, sensors, databases). To use this data, a Python program
must communicate with the data source. This communication is known as data
connectivity, which enables applications to access, retrieve, and update data
efficiently.

A database connection in Python requires five essential components working
together:

A DataFrame is the core data structure in Pandas. It is a 2D (Two-Dimensional)

##P85
4.3.2 Creating and Loading Data (Files)
Typing data manually is fine for small examples, but in the real world, data is
collected from files, spreadsheets, or online platforms. Pandas provides special
functions to load massive datasets automatically.
1. Load data from CSV file
read_csv() reads data from a Comma Separated Values file and stores it directly into a
DataFrame.
import pandas as pd
df = pd.read_csv('students.csv')
# Display the first 5 rows for quick inspection
print(df.head())
2. Load data from Excel file
read_excel() reads data from an Excel file (.xlsx, .xls). You can also specify which sheet to
read.
import pandas as pd
df = pd.read_excel('students.xlsx', sheet_name='Sheet1')
print(df.head())
👨‍🏫 What is `df.head()`?
If a file has 1 million rows, using `print(df)` will flood the screen. `df.head()` is
extremely useful because it only prints the first 5 rows, allowing the analyst
to quickly verify column names and data types without crashing the output
console.

4.3.3 Handling Missing Values
★ GOLDEN TOPIC
Missing values occur when some data is unavailable or not entered. In Pandas,
missing values are represented as NaN (Not a Number). Before analyzing data,
missing values MUST be identified and handled, otherwise they will crash
statistical calculations.
import pandas as pd
data = {
"Name": ["Ali", "Sara", "Ahmed", "Ayesha"],
"Marks": [85.0, None, 78.0, 92.0],  # Sara has missing marks
"Grade": ["A", "A", None, "A"]        # Ahmed has missing grade
}
df = pd.DataFrame(data)
Step 1: Check for Missing Values
Use isnull() to identify them. It returns True if a value is missing.
print(df.isnull())
Step 2: Count Missing Values
Use isnull().sum() to count exactly how many missing values exist in each column.
print(df.isnull().sum())
# Output will show Marks: 1, Grade: 1
Page 12

##P88
Handling Missing Values (Continued)
Once missing values are found, you have two choices: replace them (fill) or
delete them (drop).
Step 3: Replace Missing Values (Fill)
Use fillna(). A common statistical trick is to replace a missing numeric value with the
average (mean) of that column.
# Replace missing Marks with the average of the Marks column
avg_marks = df["Marks"].mean()
df["Marks"] = df["Marks"].fillna(avg_marks)
# Replace missing Grade with a custom text
df["Grade"] = df["Grade"].fillna("Not Assigned")
print(df)
Alternative Step: Remove Rows (Drop)
If replacing data is not safe, you can completely delete any row that contains a NaN value
using dropna().
# Removes ANY row that has at least one missing value
df = df.dropna()
print(df)
Summary of Missing Value Functions
isnull()
Identifies missing values (True/False).
sum()
Counts missing values when combined with isnull().
fillna(value)
Replaces missing values with a specific value.
dropna()
Deletes entire rows containing missing values.

of data. It visually displays five key values: minimum, first quartile (Q1), median

##P97
4.6 Descriptive Statistics
Descriptive statistics are mathematical techniques used to summarize,
organize, and describe large amounts of data using simple numbers. Instead of
examining thousands of individual records, we can use a single number to
understand the big picture.
4.6.1 Measures of Central Tendency
These measures aim to find the center or typical value of a dataset. The three
common measures are Mean, Median, and Mode.
1. Mean (Average)
The arithmetic average. It is calculated by adding all values together and dividing by
the total number of observations. It uses every single data value.
Mean = (Sum of all values) / (Total Number of values)
Example: Marks are 70, 80, 90.
Mean = (70 + 80 + 90) / 3 = 240 / 3 = 80
⚠️ The Flaw of the Mean
The mean is heavily distorted by extreme outliers. If 9 people earn $10, and 1
person earns $1,000, the Mean is $109. This makes the group look wealthy,
even though 90% are not! In such cases, Median is better.
Page 22

##P98
Measures of Central Tendency (Continued)
2. Median
The exact middle value of a dataset when it is arranged in ascending (or
descending) order. Unlike the Mean, the Median is not affected by extreme outlier
values.
Example (Odd count): Marks: 35, 10, 15, 70, 95.
Step 1 (Sort): 10, 15, 35, 70, 95.
Step 2: The exact middle is 35.
3. Mode
The value that appears most frequently in the dataset. A dataset may have one
mode, multiple modes, or no mode at all if no value repeats.
Example: Bottles sold: 20, 25, 20, 30, 20, 25, 20.
The number 20 appears 4 times. Therefore, Mode = 20.

4.6.2 Measures of Spread (Dispersion)
★ GOLDEN TOPIC
While Central Tendency tells us where the center of the data is, Measures of
Spread tell us how stretched or scattered the data is around that center. Are
the values tightly packed together, or wildly unpredictable?
1. Range
The simplest measure of spread. It is the absolute difference between the highest and
lowest values in the dataset.
Range = Maximum Value - Minimum Value
Example: Sales were 120, 150, 180. Range = 180 - 120 = 60.
2. Variance (σ²)
Variance measures exactly how far, on average, the data values are spread out from
the Mean. A small variance means data is highly consistent. A large variance means
data is fluctuating widely.

##P100
Measures of Spread (Continued)
3. Standard Deviation (σ)
Standard deviation is simply the square root of the Variance. It is the most commonly
used measure of spread because it is expressed in the same units as the original
data (e.g., "marks" instead of "marks-squared").
A low standard deviation means scores are very close to the average (reliable,
consistent).
A high standard deviation means scores are spread out over a large range
(unpredictable).
4. Minimum Value (Min)
The absolute smallest value recorded
in the entire dataset. Important for
finding the lower limit.
Example: Marks [70, 80, 90, 60, 75] → Min
= 60.
5. Maximum Value (Max)
The absolute largest value recorded in
the entire dataset. Important for
finding the upper limit.
Example: Marks [70, 80, 90, 60, 75] → Max
= 90.
🧠 Concept Connection

middle 50% spread, and the line inside the box is the Median.
