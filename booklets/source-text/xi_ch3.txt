##P50
3.4 Fundamentals of Python Programming
★ GOLDEN TOPIC
The basic structure of a Python program is simple and clear. It processes data
using statements, and finally shows output. Programs run top-to-bottom
sequentially.
1. Comments (#)
Comments are notes written in the code for humans. They start with the #
symbol. The Python interpreter completely ignores them.
2. Indentation (Spaces)
Unlike C++ or Java which use curly brackets {} to define blocks of code, Python
uses indentation (spaces at the beginning of a line). Indentation is mandatory!
The standard is 4 spaces (or 1 tab).
# This is a comment. It explains the code below.
print("Hello, World!")
if 5 > 2:
# The space before 'print' is the Indentation
print("Five is greater than two!")
⚠️ Common Error
If a student gets an IndentationError, tell them to check their spaces.
Mixing tabs and spaces can break a Python program.

3.4.1 Variables
★ GOLDEN TOPIC
A variable is a named space in computer memory used to store data. Think of it
as a container. In Python, you do not need to declare the type; Python figures it
out automatically.
Rules for Naming Variables:
Can contain letters, numbers, and underscores ( _ ).
MUST start with a letter or underscore, NOT a number. (e.g., 1name is invalid).
Are case-sensitive (age and Age are completely different).
Cannot use Python keywords (like if, for, while).
Valid Names ✓
name = "Ali"
age = 16
my_height = 5.7
score1 = 100
Invalid Names ✗
1name = "Ali"   # starts with
number
my height = 5.7 # contains space
if = 100        # keyword used

3.5 Control Structures
★ GOLDEN TOPIC
Control structures decide the order in which statements are executed in a
program. Almost every program uses three basic structures: Sequence,
Selection, and Repetition.
3.5.1 Sequence
Sequence means that statements are executed one after another, strictly from
top to bottom, in the exact order they are written. This is the default behavior of
Python.
print("Enter two numbers")
a = int(input("Enter first number: "))  # Step 1: Input
b = int(input("Enter second number: ")) # Step 2: Input
total = a + b                       # Step 3: Process
print("Sum =", total)               # Step 4: Output

##P59
3.5.2 Selection Statements
Selection alters the flow based on a condition (True/False). It helps programs
respond intelligently.
1. The if Statement
Executes a block of code ONLY if the condition is True. If False, the block is
completely skipped.
age = int(input("Enter your age: "))
if age >= 18:
print("You are an Adult.")  # Runs only if >= 18
print("Program continues...") # Runs every time
2. The if-else Statement
Provides TWO paths. IF true, do this. ELSE, do that. One of the blocks will always
execute.
age = int(input("Enter your age: "))
if age >= 18:
print("Apply for CNIC.")
else:
print("Apply for CRC (B-Form).")
👨‍🏫 Formatting Rule
Don't forget the colon ( : ) after if and else, and ensure the code inside the
blocks is indented!
Page 16

##P60
Selection Statements (Continued)
3. The if-elif-else Statement
Handles multiple conditions. It checks from top to bottom. As soon as it finds a
True condition, it executes that block and ignores the rest.
marks = int(input("Enter marks: "))
if marks >= 80:
print("A-1 Grade")
elif marks >= 70:
print("A Grade")
elif marks >= 60:
print("B Grade")
else:
print("Fail or below B")
4. Nested if Statement
An if inside another if. Used when a decision requires passing multiple levels
of checks.
age = 20
salary = 35000
if age >= 18:
# Passed first check
if salary >= 30000:
# Passed second check
print("Loan APPROVED!")
else:
print("Salary too low for loan.")
else:
print("Too young for loan.")

##P62
Repetition Statements (Continued)
2. The while Loop
Repeats a block of code as long as a condition remains True. Used when the
exact number of iterations is NOT known in advance.
count = 1
while count <= 3:
print(count)
count += 1   # VERY IMPORTANT: Update condition!
# Output: 1 2 3
Loop Control Statements
These statements alter the normal flow of a loop.
break
Exits/Stops the loop entirely immediately.
for i in range(5):
if i == 3:
break
print(i)
# Stops printing at 2
continue
Skips current iteration and jumps to the next.
for i in range(5):
if i == 3:
continue
print(i)
# Skips 3 (Prints 0 1 2 4)

##P63
Nested Loops & Comparison
Nested Loop
A loop inside another loop. The inner loop runs completely from start to finish for
every single iteration of the outer loop.
for outer in range(1, 3):       # Runs 2 times (1, 2)
for inner in range(1, 4):   # Runs 3 times per outer (1, 2, 3)
print(f"Outer: {outer}, Inner: {inner}")
Output:

Outer: 1, Inner: 3
Outer: 2, Inner: 1
Outer: 2, Inner: 2

##P64
Practical Activity: Shopping Bill Calculator
This program beautifully combines Sequence, Selection, and Repetition.
print("===== SHOPPING BILL =====")
total = 0.0
count = 0
shopping = True
# REPETITION: Keep adding items
while shopping:
item = input("Enter Item Name (or 'done' to stop): ")
# SELECTION: Check if user wants to stop
if item.lower() == "done":
shopping = False
else:
price = float(input(f"Enter Price of {item}: "))
# SELECTION: Validate price
if price <= 0:
print("Invalid price!")
else:
total += price
count += 1
# Summary & Discount
if total >= 5000:
discount = total * 0.20  # 20% off
else:
discount = 0
final = total - discount
print(f"Total Items: {count}")
print(f"Total Bill: {total}")
print(f"Final to Pay: {final}")

3.6 Libraries in Python
Libraries are pre-written code that offer helpful functions. Instead of writing
complex code from scratch, programmers use libraries to solve common
problems efficiently.
How to Import Libraries
There are mainly 5 ways to import a library:
Syntax
Code Example
1. Import entire module
Must use module.func()
import math
res = math.sqrt(25)
2. Import with alias (nickname)
import math as m
res = m.sqrt(16)
3. Import specific function
No need to prefix module name.
from math import sqrt
res = sqrt(36)
4. Import multiple functions
from math import sqrt, pi
5. Import everything (*)
from math import *
res = sqrt(64)
👨‍🏫 Best Practice
Advise students that importing specific functions (method 3) is better for
memory and clarity than importing everything using the * wildcard.

3.6.1 Built-in Libraries
These libraries come pre-installed with Python. You just need to import them to

1. math Library
Provides mathematical operations and
constants.

Generates random numbers or selections.

3. datetime Library
Provides classes for working with dates and times.
import datetime
# Get exact current date and time
now = datetime.datetime.now()

# Format it beautifully (Day-Month-Year)
formatted = now.strftime("%d-%m-%Y")
print(formatted) # e.g., 27-09-2026

##P68
Types of Errors (Bugs)
1. Syntax Errors
Occur when the rules (grammar) of Python are violated. The program will NOT run
at all until it is fixed.
print("Hello World"
# Missing closing parenthesis!
2. Runtime Errors (Exceptions)
The code is written correctly, so it starts running. But an impossible operation
crashes it during execution.
x = 10 / 0  # ZeroDivisionError: division by zero!
3. Logical Errors
The hardest to find. The program runs perfectly without crashing, but it produces the
wrong output because the programmer's logic is flawed.
area = length + width # Logical error: Should be multiplied (*), not added.

##P69
Reading Error Messages (Tracebacks)
When Python crashes, it prints a Traceback. It is a roadmap to fix the bug. It tells
you:
1. What type of error occurred.
2. Which file the error is in.
3. Exactly which line number caused the crash.
Traceback (most recent call last):
  File "e:\Python Code\debug_program.py", line 1, in <module>
    x = int("abc")
ValueError: invalid literal for int() with base 10: 'abc'
Diagnosis: The traceback clearly states that on Line 1, we tried to convert letters
("abc") into an integer, which generated a ValueError.
