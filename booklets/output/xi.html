2.1 Computational Thinking

Computational Thinking (CT) is a systematic approach to solving problems. "Systematic" means you follow a fixed, organised method instead of guessing. CT involves four activities:

  • Decomposition — breaking a big problem down into smaller parts.
  • Pattern recognition — identifying things that repeat or follow a rule.
  • Abstraction — hiding (ignoring) details that do not matter.
  • Algorithms — developing clear step-by-step instructions to solve the problem.

CT is not "thinking like a computer". It is thinking in a way that lets you describe a solution so clearly that a computer (or another person) could carry it out.

Problem→Decomposition→Pattern recognition→Abstraction→Algorithm→Program

You already use computational thinking in daily life. When you plan your exam preparation, you split the syllabus into chapters (decomposition), notice that every chapter needs the same routine of reading, making notes and practising (pattern recognition), ignore things that are not in the syllabus (abstraction), and make a day-by-day timetable (algorithm).

Did you know? Pseudocode is a human-readable representation of an algorithm using plain English and structured programming keywords. It is the bridge between human logic and machine code. You will study it in detail in section 2.2.2.

Remember the four parts of CT with the phrase "Don't Pick Any Apple": Decomposition, Pattern recognition, Abstraction, Algorithm.

Students sometimes think computational thinking means "writing code". It does not. CT happens before coding. You can do all four steps with pen and paper, without a computer.

کمپیوٹیشنل تھنکنگ (Computational Thinking) مسائل حل کرنے کا ایک منظم طریقہ ہے۔ اس کے چار حصے ہیں: مسئلے کو چھوٹے حصوں میں توڑنا (Decomposition)، دہرائی جانے والی باتوں کو پہچاننا (Pattern Recognition)، غیر ضروری تفصیلات کو چھپانا (Abstraction) اور مرحلہ وار حل لکھنا (Algorithm)۔ یہ سوچنے کا طریقہ ہے، کوڈ لکھنا نہیں۔

2.2 Algorithm ★ Golden

An algorithm is a step-by-step logical procedure used to solve a problem. It is conceptual in nature (it is an idea, a plan) and completely independent of any programming language. The same algorithm can be written later in Python, C++ or Java.

A good algorithm has:

  • Input — the data it starts with.
  • Clear steps — each step has only one meaning.
  • A definite end — it must finish after a limited number of steps.
  • Output — the result it produces.

Algorithm to find the larger of two numbers

Step 1: Start
Step 2: Read A and B
Step 3: If A > B, print "A is larger"
Step 4: Else print "B is larger or equal"
Step 5: End

Notice: there is no Python or C++ here. Anyone — even a non-programmer — can follow these steps. That is what "language-independent" means.

2.2.1 Importance of Algorithms

ReasonWhat it means for you
Structured approachAlgorithms provide a structured approach to problem-solving, making complex tasks manageable.
OptimisationThey optimise time and memory usage, which is crucial for large-scale applications (for example, searching millions of records).
ReusabilityThey can be reused for similar problems, saving time and effort. A sorting algorithm for marks can also sort prices.
Accuracy and consistencyThey ensure accuracy and consistency, reducing human error. The same steps always give the same result.

Remember the five reasons as S-O-R-A-B: Structured, Optimised, Reusable, Accurate, Blueprint.

Do not write "an algorithm is a program". A program is the algorithm written in a programming language so that a computer can run it. The algorithm itself is only the logic.

2.2.2 Algorithm vs Pseudocode ★ Golden

Both algorithms and pseudocode are used in problem-solving, but they serve different purposes in the design phase. The algorithm says what must be done. The pseudocode shows how it could be implemented, using programming-like keywords such as IF, FOR and WHILE, but it still cannot be run on a computer.

PointAlgorithmPseudocode
DefinitionA step-by-step logical procedure to solve a problem.A human-readable representation of an algorithm using plain English & keywords.
NatureConceptual and language-independent.Semi-formal and structured, but not executable code.
PurposeTo define what needs to be done logically.To present how it can be implemented in a readable format.
FormUsually described in plain steps, bullets or numbered points.Written using structured constructs (IF, FOR, WHILE) like programming.
FocusFocuses on the logic and steps of the problem.Focuses on representing steps clearly before coding.
AudienceFor anyone trying to understand the logic (including non-programmers).Mainly for programmers or students preparing for coding.
Format rulesNo fixed format; can be informal.Follows standard pseudocode conventions for clarity.

The same problem written both ways: print whether a number is even or odd.

Algorithm

Step 1: Start
Step 2: Read a number N
Step 3: Divide N by 2 and find the remainder
Step 4: If the remainder is 0, print "Even", otherwise print "Odd"
Step 5: End

Pseudocode

START
INPUT N
SET R TO N MOD 2
IF R = 0 THEN
    PRINT "Even"
ELSE
    PRINT "Odd"
END IF
END

The equivalent Python program (real, executable code):

n = 7
if n % 2 == 0:
    print("Even")
else:
    print("Odd")
Odd
Problem→Algorithm (what)→Pseudocode (how)→Program (code)→Output

Teacher's analogy: an algorithm is like a recipe ("Bake a cake at 350 degrees"). Pseudocode is like a structured kitchen manual using standard verbs (SET temperature TO 350; WHILE cake is not baked, WAIT). The program is the oven actually doing it.

Pseudocode is not executable. If you type pseudocode into Python, it will give errors. Also, do not mix exact Python syntax (colons, brackets) into pseudocode answers unless asked — use keywords like IF … THEN … END IF.

الگورتھم بتاتا ہے کہ کیا کرنا ہے، جبکہ سوڈو کوڈ (Pseudocode) بتاتا ہے کہ اسے کیسے کیا جا سکتا ہے۔ الگورتھم سادہ مرحلوں میں لکھا جاتا ہے اور ہر کوئی اسے سمجھ سکتا ہے۔ سوڈو کوڈ میں IF، FOR اور WHILE جیسے الفاظ استعمال ہوتے ہیں اور یہ زیادہ تر پروگرامرز کے لیے ہوتا ہے، لیکن اسے کمپیوٹر پر چلایا نہیں جا سکتا۔

1. Which one — algorithm or pseudocode — uses keywords like FOR and WHILE?

2. Which one is meant for non-programmers too?

3. Can pseudocode be executed by a computer?

Answers: 1. Pseudocode. 2. Algorithm. 3. No; it is semi-formal and not executable.

2.3.1 Decomposition ★ Golden

2.3 Algorithmic Strategies for Problem Solving. An algorithmic strategy is a general method that helps you design an algorithm. The three strategies in your syllabus are decomposition, pattern recognition and abstraction.

Decomposition is a problem-solving technique in which a complex task or system is broken down into smaller, manageable parts. By dividing a big problem into simpler steps, it becomes easier to understand, develop and solve.

Each small part is called a sub-task (or sub-problem). You solve each sub-task separately, then join the solutions to solve the whole problem.

Real-life example: Learning a new language

"Learn English" (or any language) is too big to do in one go. Decompose it:

Sub-taskDescription
Learn vocabularyLearn the words for people, actions and things (e.g., "I", "eat", "apple").
Grammar rulesLearn the sentence structure: Subject → Verb → Object.
Learn tensesPresent, past, future (e.g., "I eat" vs. "I ate").
Sentence buildingCombine words using the rules to create valid sentences: "I ate an apple."
Vocabulary→Grammar rules→Tenses→Sentence building

Computing example: a "Student Result" program

Problem: read the marks of a student in 5 subjects and print the total, percentage and grade.

  • Sub-task 1: Input marks of 5 subjects.
  • Sub-task 2: Calculate total = sum of the 5 marks.
  • Sub-task 3: Calculate percentage = total ÷ 500 × 100.
  • Sub-task 4: Decide the grade from the percentage.
  • Sub-task 5: Print the result card.

Each sub-task is now so small that you can write it in two or three lines of code.

Why is decomposition useful?

  • Reduces complexity: you focus on one piece at a time.
  • Helps in debugging: you can find exactly where the mistake is (e.g., in the language example, is the error in the verb tense or the word order?).
  • Promotes reusability: once you learn or build a small part, you can apply it elsewhere (the "calculate percentage" part can be reused in an attendance program).

Think of eating a big roti: you cannot eat it in one bite, so you break it into small pieces. Decomposition = "break the roti".

Do not break a problem into random pieces. Each sub-task must be a meaningful, clear job, and all sub-tasks together must solve the whole problem. If one part is missing (e.g., "print result"), the solution is incomplete.

ڈیکمپوزیشن (Decomposition) کا مطلب ہے کسی بڑے اور پیچیدہ مسئلے کو چھوٹے اور آسان حصوں میں تقسیم کرنا۔ مثلاً نئی زبان سیکھنے کو الفاظ، گرامر، زمانے (Tenses) اور جملہ سازی میں تقسیم کیا جا سکتا ہے۔ اس سے پیچیدگی کم ہوتی ہے، غلطی ڈھونڈنا آسان ہوتا ہے اور حصے دوبارہ استعمال ہو سکتے ہیں۔

Expect "Define decomposition with a real-life example" or "Explain the benefits of decomposition". Give the definition, draw the small tree (Complex Problem → Sub-task 1, 2, 3), show the language-learning table, and list the three benefits: reduces complexity, helps debugging, promotes reusability.

1. What is each smaller part of a decomposed problem called?

2. Decompose "Making a school timetable" into three sub-tasks.

3. State the three benefits of decomposition.

Answers: 1. A sub-task (sub-problem). 2. Example: list subjects and teachers; decide periods per subject per week; place periods in days so no teacher has two classes at once. 3. Reduces complexity, helps in debugging, promotes reusability.

2.3.2 Pattern Recognition

Pattern recognition is the process of identifying regularities, repetitions or rules in data. It helps in reducing the overall complexity of an algorithm and forms the foundation of concepts such as loops.

How it works — ask yourself three questions:

  • What is repeating?
  • What changes in a predictable way?
  • Can I generalise this (write one rule that works for every case)?

Example: Triangle of stars

*
**
***
****
*****

Step 1 — What repeats? Every row prints stars.

Step 2 — What changes predictably? Each row adds 1 star to the previous row's count.

RowStars
11
22
33
……
NN

Step 3 — Generalise: Row N = N stars. Recognising this pattern lets us write one generic loop instead of 5 separate print statements.

Without the pattern (5 statements)

print("*")
print("**")
print("***")
print("****")
print("*****")

With the pattern (one loop)

n = 5
for row in range(1, n + 1):
    print("*" * row)

Both programs print exactly the same triangle. But if you want 100 rows, the loop version needs only one change (n = 100), while the first version needs 100 lines.

Whenever you see "the same thing again and again, with a small change each time", think loop. Pattern recognition is the habit of spotting that.

Do not generalise from too few cases. Check your rule on several rows (or items) before trusting it. "Row N = N stars" is correct here; a different triangle (1, 3, 5, 7 stars) follows the rule "Row N = 2N − 1 stars".

پیٹرن ریکگنیشن (Pattern Recognition) کا مطلب ہے ڈیٹا میں دہرائی جانے والی چیزوں یا اصولوں کو پہچاننا۔ ستاروں کی تکون میں ہر قطار میں پچھلی قطار سے ایک ستارہ زیادہ ہے، یعنی قطار N میں N ستارے۔ یہ پیٹرن پہچان کر ہم پانچ الگ پرنٹ کے بجائے ایک لوپ (Loop) لکھ سکتے ہیں۔

1. Which programming concept is based on pattern recognition?

2. How many stars will row 8 of the triangle have?

3. Find the rule: 2, 4, 6, 8, …

Answers: 1. Loops. 2. 8 stars (Row N = N stars). 3. Term N = 2 × N (each term adds 2).

2.3.3 Abstraction

Abstraction means hiding unnecessary features and focusing only on the essential ones needed to solve a problem. It reduces complexity by ignoring what is not important (the noise).

When you apply abstraction you sort details into three groups:

  • Necessary steps — the core logic that never changes.
  • Changes based on the situation — these become variables (inputs) in the algorithm.
  • Abstraction items (noise) — details you can ignore completely.

Example: applying abstraction to "Making Tea"

To make an algorithm for tea, we separate the necessary steps from the situational changes and the noise.

1. Necessary steps (core logic)2. Changes based on situation (variables)3. Abstraction items (ignore / noise)
1. Boil water
2. Add tea leaves/bag
3. Steep for a few minutes
4. Pour into cup
5. Serve		 Ingredients (black, green, milk)
Additions (sugar, lemon)
Tools (stove vs kettle)		 Brand of kettle
Cup colour or design
Where tea is made (kitchen, office)

The core abstracted logic, independent of cup colour or kettle brand:

Boil water→Add tea→Steep→Pour→Serve

This one algorithm now works for green tea in an office kettle and for milk tea on a kitchen stove. The middle column simply becomes inputs: tea_type, addition, tool.

Computers use abstraction everywhere. When you call print("Hello") in Python, you do not think about how the screen lights up each pixel — those details are hidden from you. A map of Karachi shows roads and landmarks but hides every tree and car: it is an abstraction of the city.

Abstraction = "Keep the skeleton, drop the decoration." Ask: "If I remove this detail, does the solution still work?" If yes, it is noise.

Do not confuse abstraction with decomposition. Decomposition splits a problem into parts. Abstraction removes unimportant details. Also, do not throw away details that really matter — "boil water" can never be ignored, but kettle brand can.

ایبسٹریکشن (Abstraction) کا مطلب ہے غیر ضروری تفصیلات کو چھپا کر صرف ضروری باتوں پر توجہ دینا۔ چائے بنانے کی مثال میں پانی ابالنا، پتی ڈالنا، دم دینا، کپ میں ڈالنا اور پیش کرنا ضروری مراحل ہیں؛ چائے کی قسم یا چینی متغیرات (Variables) ہیں؛ جبکہ کیتلی کا برانڈ یا کپ کا رنگ فالتو باتیں (Noise) ہیں جنہیں نظر انداز کیا جاتا ہے۔

1. What is "noise" in abstraction?

2. In the tea example, is "sugar or lemon" a necessary step, a variable, or noise?

3. How is abstraction different from decomposition?

Answers: 1. Unnecessary details that do not affect the solution. 2. A variable (it changes with the situation). 3. Decomposition breaks a problem into parts; abstraction hides details that are not important.

2.4 Sorting and Searching Algorithms

Sorting and searching are both fundamental techniques of computer science. They work on lists of the same data type (for example, a list of all integers or a list of all names).

SortingSearching
Arranging a collection of items in an order. The order may be ascending (0–9, A–Z) or descending (9–0, Z–A). Used to organise data. Locating a specific element within a list to find its position or check its existence (is it there or not?).
Examples: Bubble Sort, Selection SortExamples: Linear Search, Binary Search
Real life: merit list arranged from highest to lowest marks.Real life: finding your roll number in the merit list.

Notation you will see

  • DATA — the list (array). DATA[1] is the 1st element in the textbook algorithms (counting starts at 1).
  • In pseudocode and Python counting starts at 0: DATA[0] is the 1st element. This is called an index.
  • N — the number of elements in the list.
  • PTR (pointer) — a variable that holds the current position.
  • temp — a temporary variable used to swap (exchange) two values.
  • Pass — one complete run of the inner loop over the list.

How a swap works with temp. Suppose A = 8 and B = 4. To exchange them:

temp = A (temp = 8)→A = B (A = 4)→B = temp (B = 8)

Without temp, writing A = B first would destroy the 8. In Python you may also write a, b = b, a.

Position 1 in the textbook algorithm is index 0 in Python. In exams, if a question uses DATA[1], count from 1; if it uses Python, count from 0. State clearly which one you use.

سارٹنگ (Sorting) کا مطلب ہے ڈیٹا کو صعودی (چھوٹے سے بڑے) یا نزولی (بڑے سے چھوٹے) ترتیب میں رکھنا۔ سرچنگ (Searching) کا مطلب ہے فہرست میں کسی خاص چیز کو تلاش کرنا تاکہ اس کی جگہ یا موجودگی معلوم ہو سکے۔ دونوں ایک ہی قسم کے ڈیٹا کی فہرست پر کام کرتے ہیں۔

2.4.1 Sorting Algorithms: Bubble Sort ★ Golden

Bubble Sort is an elementary sorting algorithm that works by repeatedly comparing adjacent (side-by-side) elements and swapping them if they are in the wrong order.

In each pass, the largest remaining value "bubbles up" to the end of the list, like an air bubble rising to the top of water. So after pass 1 the largest value is in the last place, after pass 2 the second largest is in second-last place, and so on. A list of N items needs N − 1 passes, and pass K makes N − K comparisons.

Compare DATA[j] and DATA[j+1]→Left > Right?→Yes: swap→Move one step right→End of pass: largest is at the end→Repeat N−1 passes

2.4.1 Sorting Algorithms: Selection Sort ★ Golden

Selection Sort is a simple sorting algorithm that works by repeatedly selecting the smallest element from the unsorted portion of the list and moving it to its correct position at the front.

Think of it as filling seats from the front: first find who belongs in position 1, then position 2, and so on. In the textbook version, the element at position K is compared with every element after it; whenever a smaller one is found, the two are swapped. So at the end of pass K, the K-th smallest value sits in position K.

Fix position K→Compare DATA[K] with DATA[PTR], PTR = K+1 … N→DATA[K] > DATA[PTR]? swap→End of pass: smallest is at K→K = K + 1

Algorithm (textbook)

Step 1: Start
Step 2: Set DATA := {8,4,1,9,3}
Step 3: Set N := 5
Step 4: Repeat Step 5 and 6 for
        K = 1 to N
Step 5: Set PTR := K+1
Step 6: Repeat while PTR <= N:
   a: If DATA[K] > DATA[PTR]:
      1. Set temp = DATA[K]
      2. Set DATA[K] = DATA[PTR]
      3. Set DATA[PTR] = temp
   b: Set PTR := PTR + 1
Step 7: End

Start

2.4.2 Searching Algorithms: Linear Search

Linear Search, also known as sequential search, works by examining each element in the list one by one, from the start, until the target is found (or the list ends). It works on both sorted and unsorted data.

A flag variable (here ValueFound) starts at 0 and becomes 1 when the item is found. After the loop, the flag tells us whether to print the item or "Not Found".

PTR = first→DATA[PTR] = FindValue?→Yes: ValueFound = 1, exit→No: PTR = PTR + 1→List ended? print "Not Found"

Algorithm (textbook)

Step 1: Start
Step 2: DATA := {8,3,6,1,7,2,4,5}

Step 5: ValueFound := 0

Step 7:   If DATA[PTR] = FindValue:
            a. ValueFound = 1
            b. Goto Step 8
Step 8: If ValueFound = 1:
          Print DATA[PTR]
        Else:
          Print "Not Found"
Step 9: End

2.4.2 Searching Algorithms: Binary Search ★ Golden

Binary Search is a highly efficient search algorithm that works by repeatedly dividing the search interval in half. Crucial limitation: it only works on a SORTED list.

Three variables mark the part of the list still being searched:

  • BEG (low) — first position of the current part.
  • END (high) — last position of the current part.
  • MID = INT((BEG + END) / 2) — the middle position. INT means "drop the decimal part".

At each step compare the item with DATA[MID]:

  • Equal → found, stop.
  • Item < DATA[MID] → the item can only be in the left half: set END = MID − 1.
  • Item > DATA[MID] → the item can only be in the right half: set BEG = MID + 1.

If BEG becomes greater than END, the part is empty and the item is not in the list.

BEG = first, END = last→MID = INT((BEG+END)/2)→Item = DATA[MID]? Found→Item < DATA[MID]: END = MID−1→Else: BEG = MID+1→Repeat while BEG ≤ END

Why is it so fast?

Every comparison throws away half of the remaining list. 1,000,000 → 500,000 → 250,000 → … → 1 takes about 20 halvings, because 220 = 1,048,576. So Binary Search finds an item among 1 million elements in at most about 20 steps, while Linear Search may need 1,000,000.

Binary Search is how you find a word in a dictionary: open the middle, decide "before or after?", and throw away half the book each time. "Sorted first, then split."

2.5 Evaluation Criteria of Algorithm

Many algorithms can solve the same problem. To judge which is better, we evaluate them on three criteria: correctness, efficiency and clarity.

2.5.1 Correctness

An algorithm is correct if:

  • its output matches the expected outcomes;
  • it handles edge cases gracefully (unusual inputs such as an empty list, 0, a negative number, or an item that is not present);
  • it is guaranteed to finish — no infinite loops.

We test correctness with a trace table (dry run): we feed sample inputs and record every value by hand, then compare the result with what we expect.

Trace table example: Even/Odd checker. Rule: divide the number by 2; if the remainder is 0 it is Even, otherwise Odd.

for number in [3, 6, 15]:
    remainder = number % 2
    if remainder == 0:
        print(number, "remainder", remainder, "-> Even")

2.5.2 Efficiency

We measure algorithm efficiency through time (speed) and space (memory). The key question is: how fast does it run as the input size grows — does it scale well?

Computer scientists describe growth with Big O notation. It counts roughly how many steps are needed for N items:

  • O(1) — constant: same time, whatever N is.
  • O(log N) — logarithmic: grows very slowly (Binary Search).
  • O(N) — linear: double N, double the time (Linear Search).
  • O(N²) — quadratic: double N, four times the time (Bubble and Selection Sort).

2.5.3 Clarity (Readability)

An algorithm must be easy to read, understand and modify. It should use clear steps, meaningful variable names and good indentation.

Unclear

a=[3,6,15]
for x in a:
 if x%2==0:print(x,"E")
 else:print(x,"O")

Clear

numbers = [3, 6, 15]
for number in numbers:
    if number % 2 == 0:
        print(number, "Even")
    else:
        print(number, "Odd")

Both work, but the second is far easier for another person (or you, a month later) to understand and change.

Remember C-E-C: Correct (right answer, always finishes), Efficient (fast and light), Clear (easy to read).

Testing only "normal" inputs is not enough to prove correctness. Always include edge cases in your trace table, e.g., the first item, the last item, a missing item, or an empty list in a search.

Choosing in practice

  • A shopkeeper's list of 15 items, written in random order, searched once: Linear Search — the list is unsorted and tiny; sorting first would waste time.
  • NADRA looking up a CNIC number among millions of sorted records, thousands of times a day: Binary Search — data is sorted, huge, and searched repeatedly.
  • A teacher arranging 40 students' marks into a merit list: a sorting algorithm; for 40 items even Bubble or Selection Sort is acceptable.
  • An unsorted list of 1 million records that will be searched thousands of times: sort it once, then use Binary Search for every search.

Two keywords decide most exam answers: "sorted?" and "how big?". Unsorted or small → Linear. Sorted and big → Binary.

"Binary Search is always better" is wrong. On unsorted data it does not work at all, and for a single search on a small unsorted list, sorting first costs more than a simple Linear Search.

Chapter 2 Review

Chapter summary

  • Computational thinking is systematic problem solving using decomposition, pattern recognition, abstraction and algorithms.
  • An algorithm is a step-by-step logical procedure to solve a problem; it is conceptual and language-independent.
  • Algorithms give structure, optimise time and memory, are reusable, ensure accuracy and act as a blueprint for code.
  • Pseudocode is a human-readable, structured representation of an algorithm using keywords like IF, FOR and WHILE; it is not executable.
  • An algorithm defines what to do; pseudocode shows how to implement it.
  • Decomposition breaks a big problem into smaller sub-tasks; it reduces complexity, helps debugging and promotes reusability.
  • Pattern recognition finds repetitions and rules (Row N = N stars) and is the foundation of loops.
  • Abstraction hides noise and keeps only essential steps; situational details become variables.
  • Sorting arranges data (ascending or descending); searching locates an element's position or existence.
  • Bubble Sort compares and swaps adjacent elements; the largest value moves to the end each pass; N − 1 passes; stable; O(N²).
  • Selection Sort brings the smallest remaining value to the front each pass; inner loop starts at outer + 1; fewer swaps; not stable; O(N²).
  • Linear Search checks items one by one; works on unsorted data; O(N) worst case.
  • Binary Search halves the search range using BEG, MID and END; needs sorted data; O(log N) — about 20 steps for 1 million items.
  • Algorithms are evaluated on correctness (checked with trace tables and edge cases), efficiency (time and space) and clarity.
  • Choose by asking: input size, sorted or not, speed or memory? Unsorted → Linear; sorted → Binary; needs order → sort.

3.4 Fundamentals of Python Programming ★ Golden

The basic structure of a Python program is simple and clear. A program takes data, processes it using statements, and finally shows output. Python runs the statements top to bottom, one after another (sequentially).

A statement is one complete instruction, usually written on one line, such as print("Hi") or x = 5.

1. Comments (#) — Comments are notes written in the code for humans. They start with the # symbol. The Python interpreter completely ignores them. Use them to explain what your code does.

2. Indentation (spaces) — C++ and Java use curly brackets { } to mark a block of code (a group of statements that belong together). Python instead uses indentation: spaces at the beginning of a line. Indentation is mandatory in Python. The standard is 4 spaces (or 1 tab).

# This is a comment. It explains the code below.
print("Hello, World!")
if 5 > 2:
    # The space before 'print' is the indentation
    print("Five is greater than two!")
Hello, World!
Five is greater than two!

Reading the program line by line:

  1. Line 1 starts with #, so Python skips it.
  2. Line 2 prints Hello, World!.
  3. Line 3 asks a question: is 5 greater than 2? The colon : says "a block follows".
  4. Line 4 is a comment inside the block (ignored).
  5. Line 5 is indented by 4 spaces, so it belongs to the if block. Because 5 > 2 is true, it runs.

What happens if you forget the indentation?

if 5 > 2:
print("Five is greater than two!")
  File "indent.py", line 2
    print("Five is greater than two!")
    ^
IndentationError: expected an indented block after 'if' statement on line 1

Python refuses to run the program and points to line 2. Add 4 spaces before print to fix it.

Think of indentation like the points and sub-points in your notebook. Sub-points are written a little to the right to show they "belong" to the main point. A colon : at the end of a line always means "indent the next line".

IndentationError? Check your spaces. Mixing tabs and spaces can break a Python program even when the code looks lined up. Choose 4 spaces and use them everywhere (VS Code inserts 4 spaces when you press Tab in a .py file).

3.4.1 Variables ★ Golden

A variable is a named space in computer memory used to store data. Think of it as a labelled container (a box with a name written on it). You put a value in it with the assignment operator =, which means "store", not "equals".

In Python you do not need to declare the type of a variable. Python figures it out automatically from the value. This is called dynamic typing: the same variable can later hold a different type.

Rules for naming variables:

  • Can contain letters, numbers and underscores (_) only — no spaces or symbols like -, @, $.
  • Must start with a letter or underscore, NOT a number (1name is invalid).
  • Are case-sensitive: age and Age are two completely different variables.
  • Cannot be a Python keyword (a reserved word such as if, for, while, else, True).

6. Bitwise operators treat numbers as binary digits (bits: 0s and 1s) and work on them bit by bit, column by column. Think of each bit as a switch that is ON (1) or OFF (0). Python's bin() function shows the binary form of a number (it starts with 0b).

3.5 Control Structures ★ Golden

Control structures decide the order in which statements are executed in a program (the "flow of control"). Almost every program is built from just three basic structures:

  1. Sequence — do the steps one after another, top to bottom.
  2. Selection — choose a path depending on a condition (if, else).
  3. Repetition — repeat steps (loops: for, while).

Morning routine as control structures:

  • Sequence: wake up → brush teeth → have breakfast.
  • Selection: if it is raining, take an umbrella; else take a cap.
  • Repetition: while the bus has not come, keep waiting.

Remember "S-S-R": Sequence, Selection, Repetition — "Step, Select, Repeat".

Selection and repetition both use conditions, but they are different: selection runs a block at most once; repetition can run a block many times.

3.5.1 Sequence

Sequence means statements are executed one after another, strictly from top to bottom, in the exact order they are written. This is the default behaviour of Python. No statement is skipped or repeated.

Input → Process → Output in sequence.

Sequence is like reading a page: line 1, then line 2, then line 3. Most programs follow the pattern Input → Process → Output.

Order matters. A variable must be given a value before it is used. Using it first causes NameError: name '…' is not defined.

3.5.2 Selection Statements: if and if-else ★ Golden

Selection changes the flow of a program based on a condition — an expression that is either True or False. It helps a program respond intelligently to different situations.

1. The if statement executes a block of code only if the condition is True. If the condition is False, the block is completely skipped.

if condition:
    statement(s)    # runs only when condition is True

2. The if-else statement provides two paths: if the condition is true, do this; else (otherwise), do that. Exactly one of the two blocks always runs.

if condition:
    block A         # condition True
else:
    block B         # condition False

5.1.1 Artificial Intelligence (AI) ★ Golden

Artificial Intelligence (AI) is the ability of a computer system to perform tasks that normally need human thinking, such as recognising faces, understanding language and making decisions.

Understand the name in two parts:

  • Artificial — it is created by humans; it is not natural.
  • Intelligence — it can perform tasks that require thinking.

AI systems use data to make decisions. The more good data an AI system sees, the better it becomes at recognising patterns (repeating features) and predicting what to do.

Examples from the source:

  1. Face recognition on a mobile phone to unlock the screen.
  2. YouTube suggesting videos based on your interests.
  3. Chatbots answering questions on a website (for example, a bank's help chat).

More Pakistani examples: Google Maps predicting traffic on Shahrah-e-Faisal, Urdu voice typing on your phone, banks flagging a suspicious card transaction, and AI tools that translate English into Urdu.

AI in smart systems

AI rarely works alone. It often acts as the "brain" of a system, working together with the Internet of Things (IoT) and Data Analytics:

  • IoT devices gather data — they are the "eyes" (sensors).
  • Analytics sorts the data — it organises and studies it.
  • AI makes the final decision — it is the "brain".
  • An action follows — something happens in the real world.
IoT (Eyes) — collects data→Analytics — sorts data→AI (Brain) — decides→Action

Smart air-conditioner in a hot Hyderabad room — trace the system:

Step 1 (IoT – eyes). A temperature sensor reads the room temperature: 36 °C.

Step 2 (Analytics). The readings of the last 10 minutes are organised: 34, 35, 35, 36 °C — the room is getting hotter.

Step 3 (AI – brain). The AI compares this with the comfortable limit (say 26 °C) and with the fact that a person is in the room (motion sensor). Decision: "Turn the AC on."

Step 4 (Action). A switch turns the AC on automatically.

No human pressed a button — the system sensed, thought and acted.

Eyes – Sort – Brain – Do. IoT is the eyes, Analytics sorts, AI is the brain, and the actuator does the action. Think of a cricket fielder: his eyes see the ball (IoT), he judges speed and direction (analytics), decides to dive (AI), and his body moves (action).

Mistake: "AI means robots." Fix: Most AI is just software — YouTube suggestions, spam filters and face unlock have no robot body. A robot may use AI, but AI itself is the thinking software.

5.1.2 Internet of Things (IoT) & Components ★ Golden

The Internet of Things (IoT) is a system in which physical devices are connected to the Internet and can collect and share data to perform tasks automatically.

The "things" are ordinary objects — watches, cameras, cars, fans, water pumps — that have been given sensors and an internet connection so they can "talk" to each other and to us.

Source example: A smartwatch collects your heart-rate data and sends it to your mobile phone, where it is displayed.

Components of IoT systems

IoT relies on six foundational components to work properly.

#ComponentWhat it doesExamples
1SensorsDevices that collect information from the physical world. They are the "eyes and ears" of the system.Temperature sensor, motion sensor, fingerprint sensor, smoke sensor, soil moisture sensor
2ActuatorsDevices that perform physical actions in response to system commands. They convert digital signals into physical movement.Electric motor, switch, automatic door opener, water valve, fan controller
3ConnectivityThe connection that allows devices to send and receive data. Without it, sensors can't talk to the system.Wi-Fi, Bluetooth, ZigBee, 4G/5G

Understanding each component

  • Sensors turn something in the real world (heat, movement, a fingerprint, smoke, wetness of soil) into data. A smoke sensor in a Karachi shopping mall "smells" smoke and reports it.
  • Actuators do the opposite: they take a digital command and make something move or change. The water valve that opens, the motor that turns, the door that slides open at a bank entrance.
  • Connectivity is the "road" for data. Short distances use Bluetooth (watch to phone); a house uses Wi-Fi; low-power sensor networks use ZigBee; devices far away in fields use mobile networks (4G/5G from Jazz, Zong, Telenor/Ufone).
  • Data processing is where raw numbers ("36") become meaning ("too hot — turn on AC"). Its four steps are collect → organise → analyse → decide.
  • Cloud computing stores and processes the huge amount of data that thousands of sensors produce every second — far more than a single small device can hold.
  • User Interface is how you see the data and give orders — an app on your phone, a touch screen on a smart fridge, or saying "Hey Google, turn off the lights".

How the components connect

Sensor (Collects)→Wi-Fi (Connectivity)→Cloud (Processes)→Actuator (Acts)→User App (UI)

Smart fire alarm in a Karachi factory — identify all six components:

Step 1 — Sensor: A smoke sensor detects smoke near the machines.

Step 2 — Connectivity: It sends the reading over the factory Wi-Fi.

Step 3 — Cloud computing: The reading is stored on an online server along with the history of all sensors.

Step 4 — Data processing: The software checks: "Is the smoke level above the safe limit?" Yes → decide "Fire risk!"

Step 5 — Actuator: Water valves of the sprinklers open and the alarm bell switch turns on.

Step 6 — User interface: The manager's mobile app shows a red alert: "Smoke detected – Hall 3".

Sensor senses, Actuator acts. Both words give you the answer: sensor = see/sense (input), actuator = act (output). Remember the six components with "Some Ants Carry Data Carefully Up" — Sensors, Actuators, Connectivity, Data processing, Cloud, UI.

Mistake: Calling a fan controller or water valve a "sensor". Fix: Ask "does it measure something or do something?" A valve opens and closes — it does, so it is an actuator. A soil moisture sensor only measures, so it is a sensor.

5.1.3 Data Analytics & Components

Data Analytics is the process of collecting, organising, cleaning, studying and presenting data to find useful information. It helps people make better decisions.

Data means raw facts and figures (for example, "72, 45, 88"). Information is data that has been processed so it has meaning ("Ali scored 72%; he passed"). Data Analytics is the bridge from data to information.

Source example: A college collects exam marks, calculates percentages, and identifies which students need extra help. This entire process is Data Analytics.

Components of Data Analytics

Data Analytics comprises five key components, which happen in order like a pipeline:

1. Collection→2. Storage→3. Cleaning→4. Analysis→5. Visualization
  1. Data Collection — Gathering raw information from multiple sources: websites, surveys, sensors, hospital records, bank transactions.
  2. Data Storage — Storing data safely and properly after collection. It can be stored in files, databases, spreadsheets or the cloud.
  3. Data Cleaning — Identifying and correcting errors in data. Raw data may contain:
    • Duplication of records (the same student entered twice),
    • Incorrect values (typos, e.g. marks "870" instead of "87"),
    • Missing files or records (a student's marks not entered),
    • Improper formats (dates written as 05/10/2026 in one place and "5 Oct 26" in another).
  4. Data Analysis — Studying the clean data to identify patterns, trends and relevant information for problem-solving (e.g. finding out which subjects students failed the most).
  5. Data Visualization — Creating visual representations of data (plots, charts, graphs) to provide valuable insights at a glance (e.g. a pie chart showing pass vs fail percentage).

Step 1 — Collection: Marks are gathered from the teacher's register.

5.2 Uses of IoT in Different Areas

IoT improves efficiency (doing more with less effort), saves time, and enhances the overall quality of life. It plays a significant role in developing modern infrastructure (the basic systems of a country — roads, power, water, hospitals). The source lists six areas.

1. Smart Cities

  • Traffic management: Sensors adjust traffic signals automatically to reduce congestion (crowding). Example: signals on a busy Karachi road stay green longer for the direction with more cars.

  • Parking: Sensors guide drivers to empty parking spaces, e.g. in a large shopping mall car park.
  • Waste management: Smart bins send alerts when full, so trucks collect only full bins instead of driving to every bin.

  • Sensors check machine temperature and vibration to prevent breakdowns (called predictive maintenance).
  • Automated machines perform repeated tasks precisely.
  • Quality-control sensors check products during manufacturing — for example, in the textile industries of Sindh, cameras and sensors spot faults in cloth as it is woven.

3. Healthcare (Smart Health)

  • Smartwatches continuously measure heart rate and vital signs (pulse, oxygen level).
  • Remote monitoring devices send patient data directly to doctors — vital for rural areas of Pakistan, where a specialist may be hundreds of kilometres away (e.g. a heart patient in Tharparkar monitored by a doctor in Karachi).
  • Emergency alert devices inform hospitals instantly, for example when an elderly person falls.

4. Education (Smart Learning)

  • Smart classrooms: digital boards and connected projectors.
  • Attendance systems: biometric automated attendance for students and teachers (used in many Sindh government schools and colleges).
  • Resource management: automated classroom lighting and AC control — off when the room is empty.

5. Home Automation

  • Smart lighting: controlled remotely via mobile apps.
  • Security: real-time monitoring via Wi-Fi cameras — you can watch your house gate on your phone.
  • Voice control: using assistants (like Alexa or Google Assistant) to control TVs and appliances.

Smart farming is crucial for agriculture in Pakistan (especially Sindh and Punjab) to save water and improve yields (the amount of crop produced).

  • Soil moisture sensors: check if crops actually need water.
  • Automated irrigation: turns water pumps ON/OFF based on soil data.
  • Drones: monitor crop health from above, spotting disease or dry patches.

5.3 Information Sources (Primary, Secondary, Tertiary) ★ Golden

Information sources are ways to find knowledge and data. The internet has vast information, but not all of it is accurate. Sources are divided into three main categories.

1. Primary sources give original, firsthand information straight from people, events or official records. They are highly authentic (genuine).
Examples: interviews, photographs, diaries, NADRA official records.

2. Secondary sources contain information that has already been collected and explained by someone else. They summarise or analyse primary data.
Examples: textbooks, news reports, research papers, Pakistan Bureau of Statistics reports.

3. Tertiary sources provide highly summarised and organised information derived from both primary and secondary sources. They are used for quick reference.
Examples: encyclopedias, Wikipedia, dictionaries, handbooks.

When do sources become unreliable?

In the digital age you must check facts carefully. A source is unreliable (cannot be trusted) if:

Source typeReasons for unreliability
PrimaryInformation is incomplete, data is recorded incorrectly, or false information was deliberately provided.
SecondaryThe information is outdated, lacks proper references/citations, or has not been verified by an expert.

Rule of thumb (Author – Date – References): If an online article does not state the author's name, the date of publication, or list its references, it should not be trusted for academic work. Remember "ADR" — like checking a bus has a driver, a route and a ticket before you board.

(d) A Bureau of Statistics report on literacy in Sindh. It analyses census (primary) data → Secondary.

5.5 Assistive Technologies ★ Golden

Assistive technologies are devices, software and systems that help people with disabilities or functional limitations (difficulty in seeing, hearing, moving, speaking, remembering, etc.). They allow more people to participate equally in school, work and society.

There are four categories:

CategoryPurposeExamples
1. Mobility aidsHelp people move from one place to another.Smart wheelchairs, stair lifts
2. Sensory aidsSupport vision and hearing to improve interaction.Hearing aids, screen readers (VoiceOver), Braille displays
3. Communication aidsAssist individuals with speech difficulties to express themselves.Speech-generating devices, text-to-speech apps
4. Cognitive / learning aidsHelp people with memory, reading and understanding.Audiobooks, spell-checkers, digital reminder apps
Mobility·Sensory·Communication·Cognitive
  • A screen reader is software that reads aloud the text on a screen, so a blind person can use a phone or computer. VoiceOver is Apple's screen reader; Android has TalkBack.
  • A Braille display is a device with small pins that rise and fall to form Braille dots, so a blind user can read screen text with their fingers.
  • A speech-generating device speaks out words that a person types or selects on a screen.
  • A smart wheelchair can be controlled by a joystick, voice or head movement and may avoid obstacles with sensors.

Scenario — choose the right assistive technology:

(a) Ahmed, a student in Hyderabad, is blind and wants to read his e-textbook. → Sensory aid: a screen reader or Braille display.

(b) Mrs Rashida cannot climb the stairs of her house after a knee operation. → Mobility aid: stair lift (or smart wheelchair).

(c) Zain cannot speak clearly due to a medical condition but can type. → Communication aid: text-to-speech app or speech-generating device.

(d) Nani often forgets to take her medicine. → Cognitive aid: digital reminder app.

(e) Usman has dyslexia (difficulty reading). → Cognitive/learning aid: audiobooks and spell-checkers.

Method: identify the limitation (moving, seeing/hearing, speaking, memory/reading) → choose the matching category.

Four categories = "My Small Cat Cries": Mobility, Sensory, Communication, Cognitive. Link each to a body function: legs (mobility), eyes/ears (sensory), mouth (communication), mind (cognitive).

Mistake: Putting text-to-speech and screen readers in the same category every time. Fix: In the source, the screen reader is a sensory aid (supports vision), while a text-to-speech app is listed as a communication aid (helps a person with speech difficulty express themselves). Decide by whose problem it solves.

5.5.1 Importance of Assistive Technologies

Assistive technologies are important for three main reasons:

  1. Equal access to education: Screen readers allow blind students to read digital textbooks equally with their peers (classmates).
  2. Independence in daily life: Mobility aids reduce the need for constant human assistance — a person in a smart wheelchair can go to the market without someone pushing.
  3. Social inclusion: They break down barriers, allowing individuals to work, study and socialise confidently.
Equal Access→Independence→Inclusion

How one tool changes a life: A visually impaired student in Karachi uses a screen reader on her laptop. Equal access — she reads the same e-books as her class. Independence — she no longer needs someone to read to her. Inclusion — she joins the class WhatsApp group, takes online tests and later gets a job, contributing to society.

Remember "AII": Access, Independence, Inclusion.

معاون ٹیکنالوجیز کی اہمیت تین باتوں میں ہے: تعلیم تک برابر رسائی (نابینا طلبہ اسکرین ریڈر سے کتابیں پڑھ سکتے ہیں)، روزمرہ زندگی میں خود مختاری (کسی کی مسلسل مدد کی ضرورت کم ہوتی ہے)، اور سماجی شمولیت (لوگ اعتماد کے ساتھ پڑھ، کام اور میل جول کر سکتے ہیں)۔

Answers: 1. Equal access to education, independence in daily life, social inclusion. 2. They reduce the need for constant human assistance.

Diagram: Sensor (collects) → Wi-Fi → Cloud (processes) → Actuator (acts) → User App (UI).

Working together: IoT is the eyes that gather data, Analytics sorts it, AI is the brain that decides. Example: a temperature sensor reads 36 °C (IoT) → recent readings are organised showing the room is heating up (Analytics) → AI decides the room is too hot (AI) → a switch turns on the AC (action).
