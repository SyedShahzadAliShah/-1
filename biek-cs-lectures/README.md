# BIEK Computer Science XI and XII lectures

Classroom lectures for the Board of Intermediate Education, Karachi, following the Sindh Curriculum for Computer Science, Grades XI–XII, 2019.

These notes are original teaching material. They are not a copy of the Sindh Textbook Board book. Before an annual examination, confirm the model paper and any reduced syllabus for that year at [biek.edu.pk](https://www.biek.edu.pk/).

## Rebuild

```bash
python3 test_programs.py
python3 build.py
```

`test_programs.py` compiles and runs every complete C++ program. `build.py` needs `reportlab`.
