# Student Formula Sheet

Print this after Session 1. Bring it to every class. Add your own errors on the back.

British spelling. CSS essays are written in this standard.

---

## 1. The sentence

- **Sentence** = subject + finite verb + complete thought.  
- **Fragment** = missing subject or finite verb.  
- **Run-on** = two sentences glued with a comma or with nothing.  
- Fix a run-on with a full stop, a semicolon, or a coordinator (*and, but, so, yet, or*).

## 2. Parts of speech (eight)

| Class | Job | CSS watch-out |
| --- | --- | --- |
| Noun | names | *information, furniture, advice* — no plural *-s* |
| Pronoun | replaces a noun | *one of them is*; *it* needs a clear noun |
| Adjective | describes a noun | *a major challenge*, not *a majorly challenge* |
| Verb | action or state | every clause needs one finite verb |
| Adverb | describes verb/adj/adv | *severely*, *well*, *never* |
| Preposition | relates a noun to the sentence | *discuss* (no *about*); *depend on* |
| Conjunction | joins | *although* OR *but*, not both |
| Interjection | emotion | almost never in a CSS essay |

## 3. Articles

- **a / an** = one of many, first mention, job/class (*a judge, an honest effort*).  
- **the** = known, unique, superlative, previously mentioned (*the Constitution, the Indus*).  
- **zero article** = general plural or uncountable (*Poverty increases unrest.* / *Water is scarce.*).  
- *one of the* + **plural noun** + **singular verb**: *One of the reasons **is**…*

## 4. Tense map (12 forms)

| Time | Simple | Continuous | Perfect | Perfect continuous |
| --- | --- | --- | --- | --- |
| Present | *the state fails* | *is failing* | *has failed* | *has been failing* |
| Past | *failed* | *was failing* | *had failed* | *had been failing* |
| Future | *will fail* | *will be failing* | *will have failed* | *will have been failing* |

**Essay default:** present simple for claims that are generally true; past simple for dated events; present perfect for a past that still matters (*Pakistan has faced energy shortages for decades*).

**Never** mix *yesterday* with present perfect.

## 5. Sequence of tenses

If the reporting or main verb is past, the next verb usually steps back:

- *He said that the policy **was** flawed.*  
- *The commission reported that funds **had been** misused.*

## 6. Subject–verb agreement

- Distance does not change the subject: *The quality of the reforms **is** poor.*  
- *Each, every, everyone, nobody, one* → singular.  
- *Either X or Y / Neither X nor Y* → verb follows the **nearer** subject.  
- *Many a* + singular: *Many a student **fails** the essay.*  
- Uncountable: *The news **is**; The police **are** (BrE).*

## 7. Voice

- Active: doer + verb + object. Prefer this in argument.  
- Passive: object + *be* + past participle (+ *by* doer). Use when the doer is unknown, obvious, or less important than the action.  
- Do not write empty passives: *Steps should be taken.* Name the actor.

## 8. Narration (reporting)

When the reporting verb is past:

| Direct | Indirect |
| --- | --- |
| *is / am* | *was* |
| *are* | *were* |
| *has / have* | *had* |
| *did / past simple* | *had* + past participle |
| *will* | *would* |
| *can* | *could* |
| *may* | *might* |
| *now / today / tomorrow / yesterday / here* | *then / that day / the next day / the previous day / there* |

- Statements: *said that…* / *told + object + that…*  
- Yes/no questions: *asked if/whether* + **statement order**.  
- Wh-questions: keep *what/why/how* + statement order.  
- Commands: *told/asked/ordered + object + to / not to*.

## 9. Conditionals

| Type | Form | Use |
| --- | --- | --- |
| 0 | *If + present, present* | laws of nature / always true |
| 1 | *If + present, will/can/may* | real future policy |
| 2 | *If + past, would/could* | imagined present (*If I were*) |
| 3 | *If + had + PP, would have + PP* | missed past chance |
| Mixed | *If + had + PP, would + verb* | past cause, present result |

- *unless* already means *if not* → no extra *not*.  
- *until* = up to a time. Do not write *until you don’t*.

## 10. High-frequency prepositions

- *interested **in**, depend **on**, consist **of**, comprise (no *of*), discuss (no *about*)*  
- *prefer X **to** Y; senior/junior/superior/inferior **to***  
- *despite* / *in spite **of*** (not *despite of*)  
- *arrive **in** a city, arrive **at** a building*  
- *angry **with** a person, angry **at** a thing*  
- *since* + point (*since 2018*); *for* + period (*for six years*)

## 11. Punctuation that saves marks

- Full stop ends a thought.  
- Comma cannot join two full sentences (comma splice).  
- Semicolon joins two related sentences.  
- Colon introduces an explanation or a list.  
- Apostrophe: *Pakistan’s economy*; *its* = possessive of *it*; *it’s* = *it is* (avoid *it’s* in essays).  
- Quotation marks for exact words; then a reporting verb.

## 12. Parallelism

After *and / or / not only…but also / both…and*, keep the same form:

- *The state must **tax** fairly, **spend** honestly and **explain** publicly.*  
- Not: *tax fairly, spending honestly and explanation*.

## 13. Pakistani English traps (memorise)

| Don’t write | Write |
| --- | --- |
| I am agree | I agree |
| discuss about | discuss |
| comprise of | comprise / consist of |
| despite of | despite |
| although… but | although… / but… |
| return back | return |
| one of the reason | one of the reasons |
| informations / furnitures | information / furniture |
| peoples (unless nations) | people |
| since five years | for five years |
| if I will go | if I go |
| unless you don’t | unless you |
| according to me | in my view / I argue that |
| the need of the hour | the priority is / Pakistan must |
| last but not the least | finally |
| did not went | did not go |
| more better | better |
| very unique | unique |

## 14. Mini paragraph formula

1. **Topic sentence** (present simple claim).  
2. **Because** (reason).  
3. **Evidence** (dated past, or present perfect for a continuing fact).  
4. **However** (limit or counter).  
5. **Therefore** (link to the thesis).

Keep one time-frame unless the meaning must move.

## 15. Before you hand the paper in

- Circle every verb. Do they agree? Is the time right?  
- Scan *a/an/the*.  
- Scan *of/in/on/to/for*.  
- Look for *although…but* and *unless…not*.  
- Read the last sentence of each paragraph. Does the next paragraph start from it?
