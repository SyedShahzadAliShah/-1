# CSS Essay Grammar Course

**17 classroom sessions** for CSS aspirants in Pakistan.

This pack teaches the **fundamentals of English grammar as a tool for essay writing**, not as isolated school grammar. Every rule is tied to what FPSC examiners actually punish: incorrect tense, broken sentence structure, weak cohesion, Urdu-patterned English, and avoidable errors.

It is written for **two users at once**:

- **Teacher:** session outcomes, 90-minute lesson plan, board work, common traps, how to mark.
- **Student:** compact notes, CSS-ready examples, drills, homework, and a self-check.

## PDF (print the course)

The full book is `CSS-Essay-Grammar-Course.pdf` (A4, cover + contents + 17 sessions + tests + keys). Rebuild after editing notes:

## Course logic

```
Parts of speech  →  Tenses  →  Sentence control
        →  Voice & narration  →  Error hunting
        →  Paragraph & essay transfer
```

Grammar is the first half of CSS English success. The Essay paper (100 marks) and the Precis & Composition paper (100 marks) both fail candidates who cannot write a clean English sentence. This course builds that sentence, then that paragraph, then a timed essay.

## Classroom assumption

- **17 sessions × 90 minutes**
- Batch of 15–40 CSS aspirants
- Mix of English-medium and Urdu-medium students
- British spelling and usage (FPSC convention)
- Homework: 45–60 minutes after each session

## What this course is not

It is not a current-affairs bank, not a quotation booklet, and not a full precis course. It is the **language engine** under a CSS essay. After Session 17, students should write a 250–300 word argument that is grammatically clean, tense-consistent, and examiner-safe. Content depth for a full 2500–3000 word CSS essay is the next course.
