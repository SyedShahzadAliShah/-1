# Session 17 — Capstone: Timed Mini-Essay and Remediation

**Module C · Accuracy and transfer**  
**Duration:** 90 minutes  
**Exam link:** full essay paper conditions in miniature; language standard for the rest of CSS prep

---

## Outcomes

The student can:

1. Plan a four-part mini-essay in 8 minutes.
2. Write **250–300 words** in 40 minutes on a known CSS-style claim.
3. Apply two-pass proofreading in 7 minutes.
4. Read a marked script against the **language rubric** and fill a remediation map.
5. Leave the course with a personal “next 30 days” grammar plan.

---

## Teacher plan (90 minutes)

| Time | Move |
| --- | --- |
| 0–5 | Rules of the room. Paper, pen, formula sheet **face down** until planning ends. No phones. |
| 5–13 | Silent outline. Teacher walks, checks that outlines are claims not headings. |
| 13–53 | **Write** 250–300 words. Teacher on the clock, no coaching. |
| 53–60 | Proofread (two passes). Formula sheet allowed now. |
| 60–70 | Scripts swapped **or** teacher samples 4 scripts on the board if the batch is small. Partners mark with the rubric (language 25, structure 15). |
| 70–85 | Remediation map. Students copy teacher’s common-fault tally. |
| 85–90 | What this course was; what the next course is. Collect scripts. |

If the batch cannot mark fairly, collect scripts, mark overnight, and use a 20-minute extra sitting for feedback. Do not skip the write.

**Traps:** students trying to produce a full 2500-word CSS essay in 40 minutes — stop them. This is a **language capstone**, not the full essay course.

**Stretch:** a fifth paragraph (counter + rebuttal) if they finish before 35 minutes with clean language.

## Student notes

### 1. What you are writing today

**Title:** A state that cannot tax fairly cannot spend honestly.

This is a **mini-essay**, not the FPSC 2500–3000 word product. It has the **shape** of a CSS essay and the **language standard** of one.

### 2. Shape (four blocks)

| Block | Words | Job |
| --- | --- | --- |
| **Opening** | 50–70 | unpack the title; one thesis sentence that takes a position |
| **Body 1** | 70–90 | tax fairness (who is outside the net; institutions: FBR / provincial boards) |
| **Body 2** | 70–90 | dishonest or wasteful spending as a result (subsidies, development funds, unbudgeted energy) |
| **Close** | 40–60 | therefore: publish, broaden, audit — named actors, *must/should*, no slogan |

Optional if fast: a short counter (*A state may tax harshly and still waste*) + rebuttal (*fairness is about who pays, not only how much*).

### 3. Opening — do not do these

- dictionary definition of *state*, *tax*, or *honest*  
- *In this contemporary era…*  
- a quotation from a poet  
- *According to me*  
- restating the title with *indeed, it is true that*

Do this:

- Explain the **logic** of the title in your own grammar.  
- End the opening with a **thesis**: *Fair taxation is the first audit of a government; without it, public spending becomes patronage.*

### 4. Language non-negotiables (today’s rubric)

You lose language marks for:

- fragments and comma splices  
- tense drift inside a beat  
- SVA faults  
- article/preposition/Urduism clusters  
- empty passives  
- *unless…not / if…will*  
- cliché list from Session 15

You do **not** lose language marks today for missing a rare current-affairs figure. Inventing a fake precise statistic **does** lose honesty marks — skip the decimal if you do not know it.

### 5. Proofreading order (7 minutes)

1. Circle every finite verb. Check tense and agreement.  
2. Scan *a/an/the* and *of/in/on/to/for/since*.  
3. Scan *although/but, unless, however* punctuation.  
4. Split any sentence you cannot read in one breath.  
5. Title-check: did you answer **tax** and **spend**, not only one?

### 6. After you get the script back — remediation map

Copy this table into the error log:

| Family | Ticks in my script | 30-day drill |
| --- | --- | --- |
| Sentence integrity (frag/splice) | | 5 repairs daily, Session 1 drill style |
| Articles / count | | uncountable list + 10 cloze |
| Prepositions | | collocation table, cover-and-say |
| Tense | | four-box grids, mixed paragraph |
| Agreement | | head-noun hunt, 10 items |
| Voice / empty passive | | name the actor |
| Narration / quoting | | 3 conversions |
| Conditionals | | 0–3 ladder |
| Punctuation | | splice → three repairs |
| Diction / Urduism | | cliché list, reverse test |
| Cohesion / topic sentence | | PEEL twice a week |

Any family with **2+ ticks** is a daily 15-minute drill for two weeks. Do not “revise everything”. Revise the wound.

### 7. What “language-ready” means (from the syllabus)

You are ready to start full-length CSS essay practice when:

- fewer than 3 grammar faults per 100 words in this timed script  
- no tense drift inside a paragraph  
- articles and prepositions mostly right  
- you can report a finding in indirect speech  
- you can use active and passive on purpose  
- you can name a fault before you fix it

If you are not there, do **not** jump to 2500-word daily essays. You will only fossilise the error. Repeat Sessions 14–16 on new topics for two weeks, then write another mini-essay.

### 8. The next course (not today)

- full outline of a 2500–3000 word CSS essay  
- introductions that are not templates  
- 8–10 paragraph architecture  
- content banks (governance, climate, economy, foreign policy, gender, technology)  
- precis, pairs of words, translation  

This 17-session pack was the **engine**. Keep the formula sheet. Keep the error log. The log is more valuable than a quotation booklet.

## Classroom materials

- Lined paper, margin for codes  
- Printed rubric (`assessments/03-final-mini-essay.md`)

## Timed prompt (write on the board)

**Mini-essay (250–300 words, 40 minutes + 8 minutes plan + 7 minutes proofread)**

*A state that cannot tax fairly cannot spend honestly.*

Take a clear position. Use PEEL in each body paragraph. British spelling. No contractions. No cliché list. Name at least two institutions.

---

## Partner marking (10 minutes)

Use the rubric. Do not rewrite the essay. Codes in the margin. A score out of 40. One gold sentence starred. One wreck bracketed.

Then return the script. The writer copies faults into the remediation map **in their own hand**. That copying is the learning.

---

## Homework (post-course)

1. Finish the remediation map with honest ticks.  
2. 30-day calendar: 15 minutes grammar drill + one 120-word PEEL paragraph, four days a week.  
3. One extra mini-essay next week on *Public education is cheaper than policing a frustrated generation.* Same timing.  
4. Keep the error log until the written exam.

---

## Exit ticket (if time; else oral)

1. What will you drill in the next 48 hours? (one family)  
2. Quote your own thesis from today’s script.  
3. Name one empty sentence you deleted in proofreading.  
4. Are you language-ready for full essays? Yes / not yet — say why in one line.

---

## Teacher mark pointers

- Mark language harder than content. A wise, broken sentence still fails CSS.  
- If 70% of the batch is “not yet”, do not start the full essay course. Repeat error sessions.  
- Return scripts with **codes**, not essays rewritten in the teacher’s English. The student must do the repair.  
- Celebrate one gold sentence publicly. The room should hear what “clean” sounds like.
