# Session 3 — Parts of Speech II: Verbs, Auxiliaries, Modals

**Module A · Foundation**  
**Duration:** 90 minutes  
**Exam link:** Tense questions; essay tone (force vs hedge); narration later

---

## Outcomes

The student can:

1. Find the **finite verb** in a clause and say whether it is lexical or auxiliary.
2. Form questions and negatives with *do / be / have*.
3. Use **modals** to control argument: *must, should, ought to, can, could, may, might, would, will, need, dare*.
4. Avoid *I am agree* and *the government should to take*.
5. Write a policy recommendation with graded force (must / should / may).

## Student notes

### 1. The verb is the engine

Every clause in a CSS essay needs a **finite verb** — a verb that shows tense and agrees with the subject.

- Lexical (main) verb: *fail, reform, tax, argue, threaten*  
- Auxiliary (helping) verb: *be, do, have*  
- Modal: *can, could, may, might, must, shall, should, will, would, ought to*

A sentence with no finite verb is a fragment: *The state trying to reform.* → *The state **is trying** to reform.*

### 2. The three auxiliaries

| Auxiliary | Job | CSS example |
| --- | --- | --- |
| **be** | continuous + passive | *The bill **is being** debated. The bill **was** passed.* |
| **have** | perfect | *The state **has** failed to tax the elite.* |
| **do** | questions, negatives, emphasis in simple tenses | *The policy **does** not work. **Does** the policy work?* |

Negatives:

- *do/does/did not* + base form: *did not **go*** (never *did not went*)  
- *is/are/was/were not*  
- *has/have/had not* + past participle

### 3. Non-finite forms (do not treat them as the main verb)

- Infinitive: *to reform*  
- Present participle / gerund: *reforming*  
- Past participle alone: *reformed* (needs *be* or *have* to be finite)

*Reforming the police* is a **noun phrase** (gerund), not a sentence.

### 4. Modal ladder for CSS argument

Modals do not take *-s*. They take a **base verb** with no *to* (except *ought to*).

| Force | Modal | When to use in an essay |
| --- | --- | --- |
| Obligation, strong policy | **must** | constitutional duty, red line |
| Advice, recommendation | **should / ought to** | good policy, not yet law |
| Ability | **can / could** | capacity of the state or a reform |
| Possibility | **may / might** | hedge; you are not a prophet |
| Future / prediction | **will** | likely result if a condition holds |
| Hypothetical / polite / past of will | **would** | type-2 conditional; reported speech |
| No necessity | **need not** | *The state need not copy every foreign model.* |
| Prohibition | **must not** | *The state must not politicise data.* |

**Wrong:** *The government should to take concrete steps.*  
**Right:** *The government should publish the true circular debt.*

**Wrong:** *It is must that we reform.*  
**Right:** *Reform is necessary.* / *Pakistan must reform.*

**Wrong:** *I am agree.*  
**Right:** *I agree.* (*agree* is already a verb. *am* is extra.)

### 5. Two extras CSS students confuse

- **used to + base:** past habit. *The rupee used to be more stable.*  
- **be used to + noun/-ing:** be accustomed. *Farmers are used to canal delays.*  
- **need** as modal (rare, formal): *The bill need not wait.* vs main verb: *The bill needs time.*

### 6. Exact verbs beat empty verbs

Examiners are tired of *take steps, do the needful, make a policy*. Prefer:

| Empty | Exact |
| --- | --- |
| take steps to improve education | fund teachers, inspect schools, publish results |
| do a law | enact / enforce a law |
| make a progress | make progress / improve |
| give suggestion | recommend / propose |
| have a look | examine |

A CSS paragraph with five *must* and no facts is still empty. Modal + **exact verb** + **object**.

### 7. Subject–verb preview (full treatment in Session 9)

*The government **has*** (singular). *The people **have***.  
*Data **are*** (BrE, plural of *datum*) — in CSS, *the data **show*** is safe; *the data **shows*** is common. This course accepts *data show/shows* if consistent; prefer *figures show* if you want to avoid the fight.

## Urdu-interference box

| Don’t | Do |
| --- | --- |
| *I am agree / I am not agree* | *I agree / I do not agree* |
| *He did not went* | *He did not go* |
| *must to / should to / can to* | *must / should / can* + base |
| *It can be able to* | *It can* / *It is able to* (one, not both) |
| *The government is trying that it should* | *The government is trying to…* |

## Class drill

**A. Underline the finite verb(s). Label lexical / auxiliary / modal.**

1. The court has struck down the ordinance.  
2. Parliament should not legislate in haste.  
3. To tax the retail sector is politically hard.  
4. The monsoon is arriving earlier than the models predicted.

**B. Repair**

5. She did not knew the rule.  
6. I am agree with the writer.  
7. Government must to reform the police.  
8. The state can be able to raise more tax.  
9. It is must that inflation is controlled.  
10. They are used to live without gas in winter. (intended: habit in the past? or accustomed?) — write **two** correct sentences, one for each meaning.

**C. Choose the modal** (must / should / may / would / must not)

11. Under the Constitution, the state ___ protect life.  
12. A wise cabinet ___ publish the debt figures.  
13. If the canal were lined, farmers ___ lose less water.  
14. An examiner ___ guess a candidate’s party politics from an essay.  
15. Next year’s flood ___ be worse; the models are not certain.

## Essay-transfer task

Theme: **Climate change is a water crisis in Pakistan.**

Write **8 sentences**. Each sentence is a recommendation or a claim. Use each of these once: *must, must not, should, can, cannot, may, might, would*.

Then recast sentence 1 and sentence 3, replacing any empty verb (*take steps, do something*) with an exact verb (*meter, line, store, ration, reforest, price*).

## Homework

1. Make a two-column list: 15 empty phrases you personally use (*need of the hour, concrete steps…*) and an exact replacement.  
2. Correct 5c–5j style items:  
   a. He was failed in the paper.  
   b. She suggested me to write daily.  
   c. The committee is agreed.  
   d. We should to consider the poor.  
   e. Did the policy succeeded?  
3. 100 words on *Why the civil service must be politically neutral.* Circle every modal. You may use *must* only twice.  
4. Error log: copy three verb faults.

---

## Exit ticket

1. Why is *I am agree* wrong?  
2. Negative of *The policy worked.*  
3. *need not* vs *must not* in one line each.  
4. Write one sentence with *should* that names a real actor and a real action.

## Teacher mark pointers

- 10: *They used to live without gas* (past habit). *They are used to living without gas* (accustomed).  
- 11: *must* (constitutional).  
- 14: *must not*.  
- Homework 2a: *He failed the paper* (not *was failed* unless someone failed him).  
- 2b: *She suggested that I write daily* / *She advised me to write daily.* (*suggest me to* is wrong.)  
- 2c: *The committee has agreed* / *The committee is agreed on a draft* (second is possible but rare). Prefer *has agreed*.
