Teacher copy. Do not print the whole file for students. Release after each attempt.

Where two answers are legal, both are listed. Prefer the **smallest change**.

## Session 1 — Class drill

1. F — *Governance without accountability **fails**.* / *Governance without accountability is theatre.*  
2. R — *The civil service recruits talent. It does not always retain it.* / *…talent, but it does not…*  
3. F — *When a state cannot tax fairly, **it loses legitimacy**.*  
4. S  
5. S (complex). Prefer a comma: *Because the census was delayed, the planning stayed blind.*  
6. R — *Social media spreads rumour. It also spreads evidence.* / *…rumour; it also…* / *…rumour, but it also…*  
7. F — *To reform the police overnight **is impossible**.* / *Nobody can reform the police overnight.*  
8. S  

### Homework 3

a. *Poverty is increasing. The government is not serious.* / *…increasing, and the government…*  
b. *Although the policy is good, implementation is weak.* OR *The policy is good, but implementation is weak.*  
c. *Pakistan **is** facing many challenges in **the** education sector.*  
d. Add a main clause: *Because the youth is frustrated, **the street fills easily**.* (Also acceptable: *The youth **are** frustrated* if *youth* is treated as plural.)  
e. *Climate change is real. It is already here.* / semicolon / *because*

### Exit ticket

1. Subject + finite verb + complete thought.  
2. Stop / semicolon / *and*.  
3. No — dependent clause, no independent clause.  
4. Simple, compound, complex, compound-complex.
