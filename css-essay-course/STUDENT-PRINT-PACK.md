# Student Print Pack — What to photocopy

Give this list to the photocopy shop / academic coordinator.

## Before Session 1 (everyone)

- `00-SYLLABUS.md` (or a 2-page extract: aims + session list + session shape)  
- `FORMULA-SHEET.md` (double-sided; students bring it every week)  
- `assessments/01-diagnostic.md`  
- `assessments/04-error-log-template.md` (several copies)  
- `sessions/01-the-css-sentence.md` — **student notes + drills only** if you are saving paper (omit the teacher plan table)

## Each subsequent session

Print that week’s `sessions/NN-….md`.  
If paper is tight: print **Student notes, Urdu box, Class drill, Essay-transfer, Homework, Exit ticket**. Skip **Teacher plan** and **Teacher mark pointers**.

## Tests

- After Session 9: `assessments/02-mid-course-test.md`  
- Session 17: `assessments/03-final-mini-essay.md` (rubric on the back)

## Never photocopy for students until after the attempt

- `answer-keys/SESSIONS-01-TO-17-KEYS.md`  
- `TEACHER-HANDBOOK.md` (optional teacher-only)

## Notebook rule (write on the board in Session 1)

Divide a register into four parts:

1. Rules (formulae only)  
2. Drills  
3. Error log  
4. Mini-writing  

Black/blue pen for first attempt. Red (or a second colour) for repair. The repair, not the first attempt, is the learning.
