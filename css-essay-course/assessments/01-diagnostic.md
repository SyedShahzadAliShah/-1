# Diagnostic Test — Session 1

**Time:** 25 minutes  
**Use:** unmarked or /50 — teacher sees the wound; student starts the error log  
**Do not teach the paper first.** Sit it cold.

Write on the script. British spelling.

---

## G. Mini-writing (10 marks)

**80–100 words.** Topic: *Why do CSS essays fail?*

Do not use a dictionary definition. Write in paragraphs. The teacher will code T / A / P / S, not line-edit.

---

## Teacher scoring (optional /50)

A–F items 1–9, 11–32 = 31 points (item 10 = 2 points for a full correct rewrite: *One of the reasons is elite capture.*). If you want a clean /40 objective + /10 writing, score A–F as 40 by treating 10 as two marks and dropping nothing; **recommended: /40 objective + /10 writing = /50**.

Writing /10:

- 4 language (verbs, articles, splices)  
- 3 sentence control  
- 3 relevance and sense  

After marking, return **codes**, not a rewritten essay. Students copy every coded fault into the error log before Session 2.
