# CS XI — Cinematic Self-Taught Teacher's Lecture Notes (Ultimate Edition)

Bilingual **English & Urdu** lecture cinema for Computer Science XI (Sindh Curriculum 2026), built from the teacher's lecture-notes edition. Designed for students who feel reluctant — short wins, coach messages, golden-topic markers, and cinematic presentation.

## Features

- **TTS narration: English and Urdu only** (Web Speech API)
- **Embedded SVG diagrams** (logic gates, waves, OSI, K-Maps, algorithms, …)
- **MathJax** for Boolean math (\(2^n\), \(Y = A \cdot B\), …)
- **2-minute wins mode** — first two slides per topic for low-friction sessions
- Chapters **1–6** with examination **★ golden** topics highlighted

## Run locally

```bash
cd cs-xi-ultimate-lectures
python3 -m http.server 8765
```

Open `http://localhost:8765` in Chrome or Edge (best TTS support). Use **▶ Narrate** or spacebar. Arrow keys change slides.

## Keyboard

| Key | Action |
|-----|--------|
| ← / → | Previous / next slide |
| Space | Play / pause narration |
