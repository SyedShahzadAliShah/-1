[y=180 x=57 B14.4] 4.11.2 Creating a Simple SELECT Query
[y=209 x=57 R12.0] A SELECT query simply picks and shows data. Steps to create one:
[y=235 x=62 R12.0] 1. Go to the Create tab and click Query Design.
[y=253 x=59 R12.0] 2. The "Show Table" dialog box appears. Select the table you want (e.g., Student)
[y=271 x=72 R12.0] and click Add.
[y=289 x=59 R12.0] 3. Double-click the fields you want to view (e.g., Name, Department). They will
[y=307 x=72 R12.0] drop down into the design grid at the bottom.
[y=325 x=58 R12.0] 4. Click the red Run (!) button in the ribbon to execute the query.
