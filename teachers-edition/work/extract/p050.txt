[y=265 x=57 R12.0] Comments are notes written in the code for humans. They start with the #
[y=283 x=57 R12.0] symbol. The Python interpreter completely ignores them.
[y=354 x=57 B14.4] 2. Indentation (Spaces)
[y=383 x=57 R12.0] Unlike C++ or Java which use curly brackets {} to define blocks of code, Python
[y=401 x=57 R12.0] uses indentation (spaces at the beginning of a line). Indentation is mandatory!
[y=419 x=57 R12.0] The standard is 4 spaces (or 1 tab).
