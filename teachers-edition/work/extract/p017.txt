[y=102 x=57 B14.4] Step-by-Step: Building Y = A · B
[y=131 x=62 R12.0] 1. Select the AND Gate from the Toolbar or Gates library and place it on the
[y=149 x=72 R12.0] canvas.
[y=167 x=59 R12.0] 2. Select the Input Pin (square icon with a 0) and place two pins to the left of the
[y=185 x=72 R12.0] gate (label them A and B).
[y=203 x=59 R12.0] 3. Select the Output Pin (circle icon with a 0) and place it to the right (label it Y).
[y=221 x=58 R12.0] 4. Use the Wiring Tool to click and drag wires from the Input Pins to the AND
[y=239 x=72 R12.0] gate's input ports. Wires must be horizontal or vertical.
[y=257 x=58 R12.0] 5. Wire the gate's output to the Output Pin Y.
[y=275 x=58 R12.0] 6. Select the Poke Tool (pointing finger) to toggle input A and B between 0 and 1
[y=293 x=72 R12.0] to test the circuit!
