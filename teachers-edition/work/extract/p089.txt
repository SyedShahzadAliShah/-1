[y=102 x=57 B14.4] 4.9.3 Creating Table using Design View
[y=131 x=57 R12.0] Design View provides full, structured control over your table before you enter
[y=149 x=57 R12.0] any data. This is the professional way to build tables.
[y=175 x=62 R12.0] 1. Go to the Create tab and select Table Design.
[y=193 x=59 R12.0] 2. Enter the Field Name (e.g., StudentID, Name).
[y=211 x=59 R12.0] 3. Select the exact Data Type from the dropdown.
[y=229 x=58 R12.0] 4. Right-click the field that should be unique and select Primary Key (a small
[y=247 x=72 R12.0] key icon will appear).
[y=265 x=58 R12.0] 5. Save the table.

[y=534 x=63 B10.8] Currency
[y=534 x=184 R10.8] Financial values like Fees or Salary.
