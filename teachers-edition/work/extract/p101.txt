[y=54 x=57 B19.2] 5.1.3 Data Analytics
[y=94 x=57 R12.0] Data Analytics is the process of collecting, organizing, cleaning, studying, and
[y=112 x=57 R12.0] presenting data to find useful information. It helps people make better
[y=130 x=57 R12.0] decisions.
[y=223 x=56 R10.8] Example: A college collects exam marks, calculates percentages, and identifies which
[y=240 x=56 R10.8] students need extra help. This entire process is Data Analytics.
[y=271 x=57 B14.4] Components of Data Analytics
[y=301 x=57 R12.0] It comprises five key components:
[y=334 x=65 B12.0] 1. Data Collection
[y=355 x=65 R10.8] Gathering raw information from multiple sources (websites, surveys, sensors, hospital
[y=372 x=65 R10.8] records, bank transactions).
[y=424 x=65 B12.0] 2. Data Storage
[y=444 x=65 R10.8] Storing data safely and properly after collection. It can be stored in files, databases,
[y=461 x=65 R10.8] spreadsheets, or the cloud.
[y=514 x=65 B12.0] 3. Data Cleaning
[y=534 x=65 R10.8] Identifying and correcting errors in data. Raw data may contain:
[y=558 x=80 R10.2] Duplication of records
[y=574 x=80 R10.2] Incorrect values (typos)
[y=589 x=80 R10.2] Missing files or records
[y=604 x=80 R10.2] Improper formats
